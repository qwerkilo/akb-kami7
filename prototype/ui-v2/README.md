## 四个方向

| 方向       | 关键词                                 | 气质            |
| ---------- | -------------------------------------- | --------------- |
| A 杂志编排 | 衬线大字、双线框、不对称网格、红色点缀 | 编辑部 / 排版感 |
| B 暗色舞台 | 深色底、紫青聚光渐变、金榜首位         | 演唱会 / 沉浸   |
| C 明亮极简 | 白底、细线、蓝点缀、大量留白           | 画廊 / 克制     |
| D 贴纸网格 | 糖果色、粗描边、硬阴影、微旋转         | 贴纸簿 / 活泼   |

## 共同覆盖

- 系列切换（48 Group / 坂道）与 7 / 16 / 32 档位切换（可交互）
- 三阶段流程：选人（筛选/搜索/已选托盘）→ 对决（进度/撤回）→ 结果（名次 + 海报 + 保存/分享）
- 海报格位随档位变化（32 → 8×4 网格）
- 坂道数据用占位头像（照片待数据管线接入）

## 约束

- 原型不进入生产代码；选定方向后再进 `to-spec` / `to-tickets`。
- 共享 mock 数据仅用于原型：48G 为 22 名真实成员（含真实头像），坂道为 12 名示意成员（占位头像）。
