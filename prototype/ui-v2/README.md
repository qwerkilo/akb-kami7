# UI v2 原型（单页四变体，`?variant=` 切换）

**原型问题**：48G × 坂道排序站 v2 应采用哪种「页面结构 + 视觉」？
四个变体在同一路由上切换，选定一个（或混搭）后折叠进正式实现；本目录是 throwaway 原型，不进入生产代码。

## 查看

单页入口（推荐）：http://127.0.0.1:8811/prototype/ui-v2/index.html

- 底部浮动切换条：`←` / `→` 或键盘方向键循环四个变体
- 直接指定变体（URL 可分享、刷新稳定）：
  - `?variant=magazine` — A · 杂志编排（编辑排版：宽幅人物条目 + 编号 + 衬线字）
  - `?variant=dark` — B · 暗色舞台（聚光深色 + 横向滑动阵容 + 前三领奖台）
  - `?variant=minimal` — C · 明亮极简（搜索优先 + 密集名单行 + 表格结果）
  - `?variant=sticker` — D · 贴纸网格（Bento 大小块 + 粗描边贴纸 + 微旋转海报）

也可以直接双击 `index.html` 打开（`file://` 同样支持 `?variant=`）。

## 共同覆盖

- 结构各异的变体（不是换色）：杂志=纵向条目流；暗色=横向胶片轨；极简=名单行 + 搜索；贴纸=Bento 拼块
- 系列切换（48 Group / 坂道）、档位 7 / 16 / 32（海报格位随档位变 8×4）
- 三阶段：选人（筛选 / 搜索 / 已选托板）→ 对决（进度 / VS / 撤回提示）→ 结果（名次 + 海报预览）
- 坂道数据用占位头像（照片待数据管线接入）
