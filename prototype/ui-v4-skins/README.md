# 皮肤切换原型（v4）

默认皮肤为「原版」（上游 11fa090 的视觉语言），可切换到「贴纸」（本项目 v2/v3 风格）。
四版只差切换器的位置与形态，皮肤实现一致（同一 DOM + 两套 CSS 变量/组件样式）。

- `a-header.html`：页头右侧（中/EN 旁）
- `b-toolbar.html`：工具行（与档位/筛选同行）
- `c-float.html`：右下浮动齿轮按钮 + 弹出层
- `d-footer.html`：页脚「外观」设置行（两张皮肤卡）

共同点：切换记忆在 `localStorage`；切换器 44px 触摸目标、键盘可达（radiogroup 方向键 / Esc 关闭弹出层）；海报导出不跟随皮肤（Q4 决定）。
