# 海报样式原型（v6）

32 人「圈内」结果海报的四种样式方向，同一份真实数据与照片（1080×1440）。

- **A 现行金字塔**：生产款（`poster.js` 贴纸皮肤），1-3-5-7-9-7 金字塔——基准对照。
- **B 杂志封面**：大标题 + 冠军横图 + 11×3 联系表网格（名字全带）——杂志编排感。
- **C 榜单领奖台**：前三放大 + 金银铜奖牌 + 4–32 名双栏紧凑榜——总选举榜单感。
- **D 贴纸拼贴**：拍立得散落 + 胶带 + 贴纸标题——手账/剪贴簿感。

## 查看

```bash
python3 -m http.server 8818 --directory <本目录>   # 或整个 worktree
# http://127.0.0.1:8818/prototype/ui-v6-poster/?v=a|b|c|d
```

页面顶部可切换四种样式，`下载 PNG` 导出当前样式；`shots/` 内为四张实拍。

## 说明

- 照片与排名均为真实数据（`members.js` + `img/full`）；字体走 Google Fonts（与主站一致）。
- A 直接复用生产 `poster.js`；B/C/D 为原型自绘（`v6.js`），落地时按所选方向改写进 `poster.js`。
