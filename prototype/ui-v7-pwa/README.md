# ui-v7-pwa · PWA 安装 / 更新 / 离线表面（四版原型）

主站要做 PWA（可安装 + 离线可用）。这一批原型只解决**用户能看见的三个表面**，
缓存策略、manifest、Service Worker 本身不在这批里。

访问：`python3 -m http.server 8819 --directory /tmp/akb-proto-pwa`
然后 `http://127.0.0.1:8819/prototype/ui-v7-pwa/?variant=A`

底部浮动条：`‹ ›` 切版本，右侧下拉切状态（可安装 / 已安装 / 有新版本 / 离线中），
页头右侧可在「原版 / 贴纸」两套皮肤间切（表面用主站同一批 CSS 变量，两皮肤都要成立）。

## 四版安装入口

| 版 | 位置 | 形态 | 说明 |
|---|---|---|---|
| **A** | 页头 `.masthead-side` | 一枚 44px 胶囊按钮「⤓ 安装」 | 与语言/皮肤切换器同一区域；每个相位（挑人/对决/结果）都在；不占版面高度 |
| **B** | 底部固定条 | 托盘上方一条黄条「装到桌面，离线也能用」+ 安装/✕ | 转化最直接；但托盘本身是 `sticky bottom`，两条要错位，且对决页无托盘时会压内容 |
| **C** | 流程内引导卡 | 与「有一场进行中的对决」卡同家族的卡片 | 零遮挡、融入阅读流；缺点是滚下去就看不到，只能首访出现 |
| **D** | 页脚 | `.colophon` 里一条虚线框「离线可用？把本站装到桌面」+ iOS 步骤 | 最不打扰；但名册很长，页脚在很下面，发现率最低 |

## 三版已定、三版共用的表面

- **更新横幅**（顶部、非阻塞）：「有新版本可用，刷新后生效」+「刷新」——绝不自动 reload，会打断进行中的对决
- **离线胶囊**（页头）：`[data-state="offline"]` 时出现，小圆点 + 「离线中」
- **iOS 指引浮层**：iOS Safari 不触发安装事件，给「分享 → 添加到主屏幕」四步说明
- 状态「已安装」：A 版按钮变绿「已安装 ✓」不再可点；B/C/D 版直接消失

## 与主站的关系

- 令牌、页头/步骤/名册/托盘结构照抄主站 `style.css` + `index.html`，数据用真实 `members.js`
  与真实照片，只是 PWA 表面用脚本模拟（真机安装事件与 SW 生命周期留到实现阶段）
