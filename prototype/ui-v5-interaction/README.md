# 交互 / UX 原型 v5 · 四方案（抛掷用）

**要回答的问题**：在功能不变（三系列 × 7/16/32 档 × 挑人 → 两两对决 → 出海报）的前提下，
**四种交互/UX 方向哪一种最值得折进主仓？**

- 单页四变体：`index.html?variant=A|B|C|D`
- 浮动切换条（底部居中）：`‹` `›` 点击切换，快捷键 `[` `]`，点中间标签弹出方案菜单。
  - 偏离说明：原型技能默认用 `← →` 切换变体；本批对决交互也要用 `← →`，故改为 `[ ]`。
- 底座是**真实数据 + 真实会话 + 真实海报**：直接加载仓库的 `core.js` / `session.js` / `poster.js` /
  `members.js`（1375 人、真实照片），变体只实现自己的「选人 + 对决」交互层；结果页与资料卡共享。
- 无持久化（内存会话，刷新即清）；无生产级打磨（无测试、错误处理从简）——原型规则。

## 现状痛点（本批要解决的）

从现状截图与代码复核（不是猜测）：

1. **首屏零面孔**：默认「全部团体」= 7 个折叠团体行；要展开「团体 → 期生」两层才见到第一张脸。
2. **进度不可见**：选人进度只在底部托盘与「还差 N 位」；无进度环、无里程碑、无团体覆盖。
3. **检索只有一档**：搜索框 + 团体下拉；无搜索建议、无「只看已选」、列表全靠两层手风琴。
4. **对决交互单一**：只有点击（键盘已有，但无手势/拖拽）；长流程（最多 129 题）**虽然自动保存但没有告知**，
   刷新续玩入口不可见；没有答题轨迹与断点。
5. **触控目标偏小**：卡片右上「i」为 26px，低于 44px 触控标准。

## 四方案

|     | 方案           | 主打交互                                                                                                       | 适合                             |
| --- | -------------- | -------------------------------------------------------------------------------------------------------------- | -------------------------------- |
| A   | **向导模式**   | 常驻三步指示器 + 引导卡 + 进度环/里程碑 + 对决说明与续玩卡                                                     | 第一次来的用户、希望「被带着走」 |
| B   | **对决驾驶舱** | 对决页当主角：VS 仪表盘、答题时间线（点缩略图回退到任意一步）、拖拽作答、断点续玩；选人页平铺无折叠 + 搜索建议 | 追求效率、愿意刷很多题           |
| C   | **选人工作台** | 桌面三栏：过滤（人数/已选）· 大画廊（无折叠）· 已选板 + 团体覆盖；移动端抽屉化                                 | 桌面/平板为主、一次挑很多人      |
| D   | **手势卡组**   | 移动优先：点选、长按看简介、卡片上拖作答、触觉反馈与转场动效；结果逐名揭晓                                     | 手机为主、想要「玩」的感觉       |

截图见 `shots/`（`v5-<方案>-<阶段>.png`：pick / picked / duel / result；`-desk` 为 1280px）。

### A · 向导模式

- 三步指示器（挑人 N/7 → 对决 → 出图）常驻可点；默认自动展开第一个团体 + 第一期生，首屏立即见脸。
- 选人：进度环 + 团体覆盖 chips + 选满里程碑 toast；对决首题前有可跳过的说明卡；对决中常显「进度已自动保存」；
  离开后回到选人页出现「继续对决」卡。
- 代价：多一层顶部导航；引导卡占用首屏高度。

### B · 对决驾驶舱

- 选人：全部平铺（无折叠）+ 搜索建议下拉（可跳转/看全部）+「只看已选」。
- 对决：仪表盘（第 N/最多 M 题、百分比、剩余、预计）+ 答题时间线（点缩略图回退到该题之后）+ 拖拽作答
  （卡片上拖松手 = 选它）+「保存并离开」/「继续对决」。
- 代价：时间线/拖拽是新机制，需要 session 暴露答题历史（当前 `snapshot()` 不含 answers，原型用序列化载荷旁路）。

### C · 选人工作台

- 桌面 ≥980px 三栏；移动端过滤与已选板折叠为顶部条 + 底部抽屉（右下浮动「已选 N/7」）。
- 左栏团体带人数与已选角标；中栏无折叠大画廊；右栏顺序列表 + 团体覆盖 + 开始。
- 代价：桌面布局改动最大；移动端是「降级形态」，不是主场景。

### D · 手势卡组

- 选人：大图卡片（2 列）+ 点选弹徽章 + 长按 450ms 看简介浮层 + 右下已选 puck。
- 对决：卡片上拖（≥56px）作答，选中卡放大打勾、落败卡淡出，下一对滑入；`navigator.vibrate` 触觉反馈。
- 代价：长按/拖拽需要真机手感验证；无障碍路径要靠点选与键盘兜底。
