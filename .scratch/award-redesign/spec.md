# Spec：获奖级视觉改版（2026-10-30）

- **Status**: ready-for-agent
- **原型**：`prototype/award-2026-10`（提交 `b1fc7df`）；截图 `/tmp/opencode/proto-shots/`
- **决策**：grilling Q1–Q10 全采纳（全站、A 编辑部 = classic、C 生写卡 = sticker 替换现有贴纸、
  系统衬线栈、先原型后实现、保留行为与验收底线）

## 目标

以 Awwwards / Webby / FWA 的**可读性与版式标准**重做视觉，而不是做炫技站：
排版、留白、层级、色彩、动效、微交互、响应式、原创性八项逐项自检，直到没有 P0/P1。

## 方向

### classic =「编辑部」

- 纸白 `#f5f2ec`、墨黑 `#16140f`、荧光粉 `#e4007f`；粉只出现在**当前步、选中、主行动**。
- 大标题用系统衬线栈（`Hiragino Mincho ProN / Yu Mincho / Noto Serif CJK`），UI 用无衬线；
  拉丁与 CJK 混排靠字号/字重/字距建立层级，不引入新字体文件。
- 巨大序号（01–07）是贯穿全站的签名元素：步骤、卡片选中、榜单、海报排名。
- 细规则线、方形图片、零圆角或 2px；双框卡片取消；留白按 8 的倍数放大。

### sticker =「生写卡」（替换现有贴纸皮）

- 暖纸 `#f1e7d8`、白卡 `#fffdf7`、胶带黄 `#f3d98b`、印章红 `#c0392b`。
- 照片卡 = 拍立得（白边、胶带、轻微旋转）；选中盖「選」章；托盘是迷你生写。
- 结果页 = 剪贴簿：胶带、印章、纸感海报；按钮是贴纸（硬阴影 + 按压缩进）。
- 与 classic 共享 DOM 与版式骨架，只换材质与细节（不复制结构）。

## 全站结构（两皮肤共用）

1. **页头**：品牌 + 语言/外观/卡片工具；窄屏「语言 + 更多」，宽屏工具文字化（不再一排 pill）。
2. **步骤条**：`01 挑人 / 02 筛选·对决 / 03 出图`，当前步粉色序号，细线分隔。
3. **挑人**：编辑级 hero（标题 + 已选大数字）→ 档位文字 tab → 团头 → 照片栅格 → 细托盘（迷你槽位）。
4. **筛选**：左标题/进度、右名单；划掉 = 灰度 + 删除线；底部提交；移动端单列 + 常驻底栏。
5. **对决**：两张 3:4 大图 + 巨大序号 + VS；进度与撤回；移动端两列不换行。
6. **结果**：左海报（编辑部跨页 / 剪贴簿），右作品信息；移动端海报在前、底部常驻动作条
   （复制/分享/保存）；桌面不重复动作条。
7. **弹层**：简介、更多、PWA 指引沿用同一材质语言（classic 纸感、sticker 贴纸）。

## 不变量（不可回退）

- 行为与导航语义不变；`core/session/poster` 的公开行为不变。
- 首屏完整可见的脸 ≥ 一行（`e2e:first` 判据）；无横向滚动。
- 卡宽三档、44px 命中区（L12 的范围）、对比度 ≥ 4.5、`prefers-reduced-motion` 全关。
- 分享链接、PWA 离线、筛选/对决/结果流程、海报四样式全部保留。
- 首访字节不显著增加（不新增字体文件；CSS gzip 增幅 ≤ 15%）。

## 验收

- `npm run check` exit 0；`npm run e2e:all` 5/5（新增检查显式计入 `EXPECT`）。
- 视觉：同条件截图（390 / 1280 × classic / sticker × 四相位）逐对比；八维自检表无 P0/P1。
- 变异：新接线（移动动作条、筛选底栏、选中章）各有至少一个变异被杀；纯样式不可变异项写明。
- 结束时更新 ADR-0020 修订段与 CONTEXT 皮肤词条。

## 不做

- 不做 B「舞台」方向（用户未选；原型保留作参考）。
- 不新增第三皮肤；不改数据管线；不引入新字体；不改海报导出算法（只改绘制参数与视觉）。
