# 02 · 首屏见脸：引导卡压成细条 + 筛选收进面板

- **Status**: resolved
- **所属 spec**：`.scratch/visual-award/spec.md`
- **依据**：`docs/adr/0020-visual-language.md` §9

## 内容

1. **引导卡 → 一行细条**：标题 + 「知道了」+「?」；正文进浮层（复用 `openSheet` 机制）。
2. **9 个筛选控件 → 一行 + 面板**：档位 3 + 状态 3 + 「筛选」按钮（显示当前命中数）
   - 搜索入口；团体/期生下拉与搜索框进面板。
3. 顺带修**步骤条第 2 枚换行**（现状「Screen / Duel」在窄屏换行成两行，77px 步骤条
   里视觉不平衡）。
4. 顺带修**托盘半透明导致名册卡片透出重叠**（现状 `rgba(…,.94)`，帮助文案与卡片重叠）。

## 涉及缝

- ⑦ E2E（`app.js` 无单测缝，接线层只有 E2E 能抓）
- ③ `test/style-artifact.test.js`（窄屏规则不许被删）

## 实测结果

第一张成员卡 top：**738 → zh 393 / en 395 / ja 393**（判据 ≤400，余量 5~7px）。
首屏可见的脸：0~1 张 → **6 张**。逐项省下的：引导卡 199→56、工具条 176→36（4 行→1 行）、
步骤条 77→57、团头 47→35、名册上内边距 14→8、块间外边距 38→24。

## 判据

- **390×844 下第一张成员卡的 `top` ≤ 400px**（现状 738）
- 三语言 × 7/40 档 × 两款皮肤都满足
- 筛选面板里的下拉与搜索与原先行为一致（筛选后计数、期生归一等）
- 页头横账不回退（`verify-header.cjs` 54 状态仍全绿）

## 途中修掉的两个真缺陷

- **档位段换行（英文界面）**：`.seg-size` 的 flex 基准是 auto（内容 288px）而容器是
  `flex-wrap: wrap` —— 换行按**基准尺寸**决定，还没轮到收缩就换行了（288 + 触发 147
  = 449 > 358）。改成 `flex: 1 1 0` + 段内 `nowrap` + 横向滚动后恢复一行。
  第一版我写的是 `1 1 auto`，症状是「改了没反应」。
- **托盘半透明**：`--tray-bg` 是 94% 不透明，名册卡片从下面透出，提示文字与卡片名
  叠在一起（截图可见）。改成不透明。

## 备注

- 引导卡收起会让「首屏见脸」这条验收项**真正成立**（此前只在关掉引导卡后成立）。
- **E2E 脚本要改两处**（不入仓）：① 筛选控件进了折叠面板，脚本点它们之前要先展开
  （加了 `openFilterPanel` 助手）② 托盘不再半透明。改的是入口不是行为。
- **PWA 套件那次失败是脚本自身的缺陷**：`serve.py` 只吃端口、docroot 来自进程 cwd，
  而 `e2e-pwa.cjs` 把目录当第二个参数传（被忽略）且没设 cwd → 从 /tmp 跑就整页 404，
  症状看起来像产品坏了（SW 不接管、壳预缓存 0 条、字体 0 face）。已修 spawn。
- 正文 15 → 16px 仍未做：它会改变所有文本宽度，横账要连同工单 03 一起量。
