# 视觉升到「杂志感基调 + 效率区降密度」

- **Status**: ready-for-agent
- **日期**：2026-09-30
- **依据**：`docs/adr/0020-visual-language.md`、方向板 `prototype/ui-v8-tone`（用户选「杂志感 + 效率区降密度」）
- **红线**（grill 已确认）：两款皮肤各自的样子（贴纸皮只保证不破）、三语言、档位 7/16/40、
  海报四样式与跟随皮肤、E2E 几何断言（变了要逐条说明）、`core/session/poster` 模块边界、
  令牌等值守卫（`poster.js` 兜底与 CSS 逐值相等）

## 目标

把「做得干净」推到「值得停下来看」，同时不牺牲效率区的一屏一步。四个可验收切片：

1. **刻度与令牌**：字阶 5 级 + 间距 4 的倍数 + 中性阶 6 级 + 动效三档时长，并把三处
   对比度欠账清到硬指标之上
2. **首屏见脸**：引导卡压成一行细条（正文进「?」浮层）+ 9 个筛选控件收成一行 + 面板
3. **动效三时刻 + 层级分隔**：进场 stagger / 点选反馈 / 切屏转场；40 档 106 题时的组间分隔
4. **结果页揭幕**：两张脸合并成一张海报的共享元素转场（签名时刻）

## 非目标

- 不改核心逻辑与档位语义（`core.screenRounds` / `screenTiers` / 排序引擎不动）
- 不改海报四样式的构图与 `poster.js` 的绘制逻辑（只同步令牌值）
- 不把贴纸皮升到同一水准（ADR-0020 §7）
- 不做编排级动效时间线、不做手势加速（ADR-0020 判否项）
- 不合并两套皮肤

## 行为规格

### 切片 1 · 刻度与令牌

- 新增字阶令牌（12/14/16/20/28）与间距令牌（4/8/12/16/24/32），把 `style.css` 里
  散写的字号与间距映射过去；**消除 7px / 14px 这类刻度外产物**
- 中性阶补到 6 级（同一冷灰色相），主色 `#e4007f` 不动
- 动效令牌三档（120/200/320ms）+ 一条缓动；`prefers-reduced-motion: reduce` 时全部关闭
- 对比度硬指标：正文/次要文字/图标 ≥4.5:1；占位图首字 ≥3:1
  （现状 `--muted` 在页底 4.33、`--peach` 作正文 3.96、占位首字 2.11）
- 令牌改动**必须同步** `poster.js` 的 `defaultTokens()`（等值守卫）
- 修 `.kami` 的 `::after` 洋红条压字（改成随字号的偏移，窄屏不再压字面）

### 切片 2 · 首屏见脸

- 引导卡 → 一行细条：标题 + 「知道了」+「?」；正文进浮层
- 筛选控件 → 一行（档位 3 + 状态 3 + 「筛选」按钮 + 搜索入口）+ 面板承载下拉与搜索
- **判据**：390×844 下第一张成员卡的 `top` ≤ 400px（现状 738）

### 切片 3 · 动效三时刻 + 层级分隔

- 进场 stagger（名册卡）、点选反馈（选中态）、切屏转场（三步之间）
- 对决页层级可见化：组切换的一次过渡 + 组内题数独立指示（细条里已有「第 t/n 组」文字，
  但视觉上没有分组感；40 档 106 题时会迷失自己在哪一组）
- 全部尊重 `prefers-reduced-motion`

### 切片 4 · 结果页揭幕

- 两张脸 → 一张海报的共享元素转场；≤400ms 完成
- 不改变更新流程（仍需用户点「刷新」才切，ADR-0016）

## 涉及缝

- ① 产物不变式：令牌等值守卫、`<html data-skin>` 不变式（缝③ `test/style-artifact.test.js`）
- ⑦ E2E 黑盒：首屏第一张脸的位置、横账预算、动效降级、揭幕时长
- `app.js` 无单测缝 → 切片 2/3/4 的接线只能靠 E2E

## 验收

- `npm run check` 全绿
- 首屏判据：390×844 × 三语言 × 7/40 档 × 两款皮肤下第一张卡 `top` ≤ 400
- 对比度判据：三处欠账全部达标（数字由测试钉住，不靠观感）
- 动效判据：`prefers-reduced-motion: reduce` 下无 transition/animation
- E2E 几何基线（页头 66/60、托盘 81/84、文档高 = 视口）逐条说明变化原因
