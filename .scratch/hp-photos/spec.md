# spec：早安家族照片缺口（75 人）

## 问题

早安系列 169 人里 **75 人没有照片**（全在毕业者与已停止活动的团）。现状链只有 Commons
一节（命中率 ≈ 0），站上显示占位卡。用户要求：**不解决不能 push**。

## 事实（2026-10-03 调研，60+ 请求、≥3s 节流、无 429）

| 源                      | 抽样  | 覆盖 75 人 | 形状                                                                            |
| ----------------------- | ----- | ---------- | ------------------------------------------------------------------------------- |
| **现官网 `/og/`**       | 37/37 | **18**     | 静态 HTML，`MemberPanel` 块 + `/upload/images/<sha1>.webp`（500×500）+ `nameJa` |
| **旧官网 Wayback**      | 9/10  | **~66**    | 3 代形态（见下）；图 102–475px                                                  |
| ja.wikipedia 非自由文件 | 0/16  | ≈0         | 死源                                                                            |

旧官网三代形态：

1. **2004–09**：`/<group>/profile.html` 或 `/artist/NN/NN/`；图 `/berryz/img/<romaji>.jpg`、
   `/images/artist_photo/<group>NN_s.jpg`（序号图，`alt` 带姓名）
2. **2010–13**：`og/<romaji>_s.jpg`、`<group>/<romaji>_NN_img.jpg`
3. **2014–23**：`/<group>/profile/<romaji>/` 页 → `cdn.helloproject.com/img/rotation/<sha1>.jpg`（`alt=姓名`）

估算残留 **~5–9 人**（後藤真希等已离开事务所、早期成员无官网快照、在籍仅数月者）。
**风险**：扁平文件名会被后来阵容覆盖 → 必须核对捕获时间戳与在籍期。

## 决定（grill 2026-10-03，五问全采纳）

1. **目标口径**：尽力找 + 残留显式化。硬目标 = 「每个缺图成员都被全部源试过」；
   残留者保留占位卡、逐人写明原因（**不伪造、不用非肖像图**）。
2. **源与顺序**：两源都做，先 `/og/` 再 Wayback；按姓名去重。
3. **匹配规则（防张冠李戴）**：三条证据任一成立才算命中 —— ① 页面或 `alt` 有姓名；
   ② 文件名是罗马字姓名且能对应；③ 序号图靠「页面 alt 顺序 + 该团在籍名单」映射。
   **三条都追加同一前提：Wayback 捕获时间戳落在该成员在籍期内**
   （`join` ≤ 捕获时间 ≤ `end`；`end` 缺失时用该团的 `GROUP_END_YEAR`）。
4. **质量底线**：不设硬下限、全部收（有脸 ≫ 占位卡）；产物报告按分辨率分档列出。
5. **实施**：本 spec + 3 张工单，逐张 TDD。

## 验收

- 缺图人数从 **75** 降到 **残留名单长度**（预期 <10），且残留逐人有原因记录。
- 产物守卫：缺图名单 ≤ 残留名单（新增缺图必须红）。
- 站内不出现张冠李戴：每条命中都要过匹配规则（测试覆盖三种证据 + 在籍期边界）。
- 三套 E2E 与 `npm run check` 全绿。
