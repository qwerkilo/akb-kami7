- **Blocked by**: 01（共用「姓名→照片」映射的接入点与测试夹具风格）

## 目标

从旧官网快照里给毕业成员配照片，覆盖缺口的大头。**三种形态**（见 spec 事实节）。

## 判据（可证伪）

1. **每团一条 CDX 查询**（`photo_chain.cdx_rows` 复用）拿到该团旧站页的快照清单；
   对每个候选快照：抓页 → 解析「姓名 → 图 URL」→ **在籍期校验**（Q3）。
2. 三种形态各有 fixture + 特征断言；**在籍期校验**是纯函数（`tenure_ok(member, ts)`），
   边界（等于 join / 等于 end / end 缺失用团终年）各一条测试。
3. 命中率：真实跑一遍后缺图人数显著下降（目标 <10）；**残留逐人有原因**
   （离开事务所 / 无快照 / 在籍过短），写进工单记录与产物报告。
4. 不张冠李戴：序号图（`cute01`）必须靠「页面 alt 顺序 + 该团在籍名单」映射；
   测试里放一个「后来阵容覆盖同名文件」的用例，断言**不被采纳**。
5. 变异 ≥3 全杀（含「去掉在籍期校验」）。
