- **Status**: ready-for-agent
- **Blocked by**: 01、02

## 目标

真实重跑管线，把缺图人数降下来；残留名单进产物报告与守卫；三套 E2E 回归。

## 判据（可证伪）

1. `members.js` 重生成：缺图人数 **75 → <10**（以实际为准），逐人原因记录。
2. 新增产物守卫（缝③）：**缺图名单 ≤ 残留名单**（新增缺图必须红）——
   名单写进 `test/members-artifact.test.js` 或工单记录所指位置。
3. `img/full` 与 `img/thumb` 都有新文件、非空（`img` 真值来源是站内文件）。
4. 照片分辨率分档报告（Q4）：写进工单记录。
5. `npm run check` 全绿；三套 E2E（主/v5/PWA）回归；变异 ≥2 全杀。

## 收口（2026-10-04）

**结果**：`members.js` 重新生成，全站 **1544 人、1521 有图（98.5%）**；早安系列 169 人、
缺图 **23**（起始缺 75）。

过程中修掉的（全部有测试或实测）：

1. `decode_page`：旧官网 2005 前后的页是 Shift_JIS，一律 UTF-8 解 → ALT 姓名乱码
   （早期モー娘。一个都配不到）。
2. `parse_img_pairs` 大小写不敏感（那些页写 `SRC=`/`ALT=` 大写）。
3. URL 归一：`…com:80/…` 与 `…com/…` 是同一资源，不归一会被预算截掉。
4. 每团预算 12→70、limit 150→900（40 时モー娘。只配到 29 人）。
5. 旧站与 `/og/` 的图一律套 Wayback（cdn.helloproject.com 对脚本一律 403，
   实测 43 张下载全失败）。
6. `download` 单张失败重试 3 次、不崩整轮；`compress_members` 过小图（1×1）按缺图处理
   （第一次实现用 `continue` 跳过 img 赋值 → 整轮在最后一步 `KeyError: 'img'` 崩掉，已修）。
7. 管线边缘 `retries=8`（48pedia 521 会连穿默认 4 次）。

**残留 23 人**：1997–2001 期モー娘。（石黒彩/市井紗耶香/後藤真希/福田明日香）、
℃-ute 3、アンジュルム 4、Juice 3、つばき 1、OCHA 2、Berryz 6（旧站快照里是 1×1 占位图）。
多数是「旧站没有他们的页」或「只有占位图」，属源的真实上限。

**验证**：`npm test` 276 JS + 237 Python 全绿；回归 E2E 240/245（5 条为既有脚本问题，
0 新红）；v5 54/54；PWA 43/43。
