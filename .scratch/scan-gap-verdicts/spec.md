# Spec：旧站扫描的截断原因收成「每团结局」（第五轮扫描候选 9）

- Status: resolved
- 来源：第五轮架构扫描候选 9（Speculative）——「截断原因『枚举→三集合→中文』两次翻译」

## 问题

同一个事实（该团这轮扫描的结局）有三份表示：

| 层     | 表示                                    | 位置                                              |
| ------ | --------------------------------------- | ------------------------------------------------- |
| ① 枚举 | `cut`：`None`/`"budget"`/`"limit"`      | `_scan_tasks`                                     |
| ② 记账 | 三个集合 `scanned`/`exhausted`/`capped` | `_resolve_old_site_groups`                        |
| ③ 文案 | 中文串 ×3                               | `_note_scan_gaps`（两个循环 + `setdefault` 顺序） |

而**每团的结局是四选一**：没轮到 / 预算截断 / 上限截断 / 扫完 —— 三集合 + 隐式补集
编码了四值，再加一层翻译。加第四种截断要改三处。

顺带核出真缺口：「旧站未扫到（全局上限）」这一类**全仓没有测试**。

## 决定（grill 2026-10-07）

| #   | 决定                                                                                                                                               |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| Q1  | 每团一个**结论**：循环里当场写 `verdicts[group] = 原因串或 None`（没轮到的团不进表）；删三集合与第二循环；`_note_scan_gaps` 退化成「按成员查结论」 |
| Q2  | 先补缺失那类的特征测试（没轮到 → 「旧站未扫到（全局上限）」）再动                                                                                  |
| Q3  | 变异 2 条：①预算/上限两类对调 ②去掉「没轮到」判据                                                                                                  |

## 验收（可证伪）

1. 新特征测试（没轮到那类）在重构前绿、在「去掉该判据」的变异下红（承重）。
2. `_resolve_old_site_groups` 里不再有 `scanned`/`exhausted`/`capped`；原因串的
   **代码定义点**各一处：`_CUT_REASON` 两个、`_note_scan_gaps` 一个
   （口径 = 代码定义点，不含 docstring 引用 —— 「旧站未扫到（全局上限）」在
   `_note_scan_gaps` 的 docstring 里另有一处说明性引用）。
3. 328 条 Python 单测全绿；`npm run check` exit=0。
4. 变异 2/2 被杀。
