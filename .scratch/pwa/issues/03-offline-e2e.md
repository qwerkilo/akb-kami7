## 交付实况

`/tmp/opencode/e2e-pwa.cjs` **30/30**（复审前只 19 项且有两条断言其实从未执行，已重写）：

1. SW 注册并接管，壳预缓存 14 条。
2. 断网瞬间离线胶囊出现（活文档路径）；断网重载后名册照常渲染；**断网后现展开一个从未浏览过的段**（SDN48 穐田和恵）→ `naturalWidth=0` + `.ph` 占位底色 `rgb(228,231,238)`；已浏览成员仍有照片。
3. 断网下完整走完 挑人 → 对决 → 结果页（9 题 = 7 人归并对决的题数），海报脸部区域取样色彩 1500+ 种（**真的有脸**，不再是只有底色）。答题循环的退出条件用「结果视图真的出来了」而不是步骤条——步骤条会先于视图切换，用它会提前收工。
4. 字体：在线 `document.fonts.size=496`、h1 宽 160；断网重载后同样是 496 / 160（首访即预热，不是第二次访问才成立）。
5. 恢复网络后胶囊消失。
6. 未捕获安装事件时页脚安装行不出现（选型 D 的取舍）；合成 `beforeinstallprompt` 后出现、点安装变「已安装」态、切语言后仍是「已安装」（复审修的 `data-i18n` 漏改）。
7. 钩住 `unhandledrejection`：正是它抓到「字体加载失败 → 海报画不出来」那个缺陷；现在断网全程零未处理拒绝。
8. iOS 路径用**另开的 iPhone UA 上下文**真跑：安装行直接出现 → 点「安装」落到四步浮层 → 遮罩挡住背后的点击 → Esc 关闭并把焦点还给触发者。
9. 更新横幅：临时副本换 `VERSION = "v2"` 的 sw.js → 出现横幅且**当前页面未被自动刷新** → 点刷新后 v2 缓存生效。
10. 无 JS 报错（断网阶段的 `net::ERR_FAILED` 属预期噪声，已过滤并注明）。

回归：`npm test` JS 136 / Python 全绿；`e2e.cjs` 86/86；`e2e-v5.cjs` 49/49。仓库零污染（第二版 sw.js 只存在于 `/tmp` 副本）。

注意：Playwright 的 `setOffline(true)` 在**重载后**会让 `navigator.onLine` 假回 true，所以离线胶囊只能在活文档里验；真机冷启动那条路径靠产品逻辑（同一个 `navigator.onLine`）覆盖。
