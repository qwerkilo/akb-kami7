# 加入早安少女家族（モーニング娘。）作为第四个系列

- **Status**: ready-for-agent
- **依据**：两轮 grilling（8 条决策全采纳）、ADR-0021（系列边界）、`CONTEXT.md`
  新增的「早安少女系列」与「Modeshi 7」词条
- **规模**：现役 11 + 毕业约 38 = 约 49 人（对比：等爱三团共 37 人）

## 决定（grilling 2026-10-02）

1. **只收モーニング娘。一个团**，作第四个系列。不收 Hello! Project 伞下的其他团 ——
   见 ADR-0021。
2. **卒業 / 脱退一律记为毕业**（站内 `status` 只有 `current` / `former` 二值，
   等爱也有同款混用而从不区分）。**不引入第三个状态。**
3. **昵称一格多行**：资料卡显示第一个，其余作为别名进搜索用的 haystack。
4. **身高与星座缺失就缺着**。早安的官网详情页与 ja.wikipedia 都没有这两项，而
   `core.profileRows` 是 `if (value)` 才入行 —— 缺字段等于少一行，不显示空值。
   不为它另找数据源。
5. **毕业成员的头像走三级回退**（Web Archive 旧列表页 → OG CDN → Wikipedia
   Commons），预计缺口集中在 1~5 期。**占位卡是既有机制，且占位不触发删图**，
   所以缺口是安全降级。开工时先跑一次真实抓取，把缺图名单打出来再决定要不要继续挖。
6. **7 档品牌名叫 Modeshi 7**（中文「推し7」/ 英文 Modeshi 7 / 日文「推し7」）——
   早安没有选拔文化，Modeshi（每位成员点名一位更低期的推し）是它唯一能与「7」
   对话的制度。
7. **三语标签与短标签**：zh「早安少女家族」/「早安」、en「Morning Musume」/
   **「MM」**、ja「モーニング娘。」/「モー娘」。
   短标签存在的唯一理由是窄屏横账 —— 实测 390/414/560px × 三语 × 短/全名共
   18 个状态，只有 **en 全名 × ≤414px** 两个红（tab 宽 143px，被「更多」压住点不到）。
   ja 全名 107px、zh 全名 94px 都装得下，所以 ja/zh 的短标签可以带信息而**零 CSS
   改动**。
8. **照片回退链按「站点无关 / 站点有关」拆开**：与站点无关的三段（CDX 查询、
   Wayback 取图、Commons 取图）提到共享模块，等爱与早安都从它 import；站点有关
   的（旧列表页 HTML 提取）留在各自 loader。这与既有的 `wiki.py` / `roster.py`
   同一做法。

## 机械项（grilling 后直接定的，不需再议）

- 系列 id `morning`（与 `love` / `sakamichi` / `48g` 同为短 id）
- 海报文件前缀 `morningmusume`；海报标签 `#モーニング娘。`（沿用等爱用官方日文名的做法）
- i18n 键：`series_morning` / `series_morning_short` / `title_prefix_morning` /
  `brand_7modeshi`，**三语各一份**
- 测试夹具 id 前缀 `m1`–`m40`（与 `a` / `s` / `l` 同级）

## 数据源（已实测）

| 用途                                              | 源                                                                          | 状态                                                                                  |
| ------------------------------------------------- | --------------------------------------------------------------------------- | ------------------------------------------------------------------------------------- |
| 现役成员 + 头像                                   | `https://helloproject.com/morningmusume/`（**必须带尾斜杠**，不带返回 404） | Astro 服务端渲染，不需要浏览器；照片是内容哈希文件名，只能靠 DOM 相邻关系配对         |
| 现役资料（昵称/生年月日/血液型/出身地/特技/趣味） | 官网详情页 `/morningmusume/<romaji_slug>/`                                  | 实测字段齐全，**没有**身高/星座/期生/状态                                             |
| 期生、毕业状态、毕业日                            | ja.wikipedia 主条目的 `=== メンバー ===` 与 `=== 過去のメンバー ===` 两表   | 现役 11 行、毕业 41 行；**毕业表也有「加入期」列**，所以两都拿得到期生                |
| 毕业成员头像                                      | Web Archive 旧列表页 → OG CDN → Commons                                     | 1073 份快照（2009-04 至 2026-09），**2009-04 之前一份都没有**；Commons 实测命中 18/50 |

**不能复用等爱的 parser**：等爱的 `parse_member_chunk` 要求 `{{生年月日と年齢` 模板、
出身地单元格以 `[都道府県]$` 结尾，而早安的表格生年月日写成
`1999年{{Display none|0}}10月{{Display none|0}}7日{{Center(…)}}`、出身地整格被
`{{Display none|…}}` 包裹，且有 `rowspan="2"` 合并单元格（逐行切会串行）。
把等爱的 parser 套上去的实测结果是 **0 人**。

## 验收

- `npm test` 全绿（现为 255 JS + 116 Python）
- 回归 E2E / v5 / PWA 三套全绿，且**要加第四个系列的流程**
- `test/members-artifact.test.js` 的三张表与那条系列集合断言更新
- 真实抓取一次，产出**缺图名单**（预计 5~13 人）
- 版式基线不动：390px 下页头 66/60、首卡 ≤400、托盘不透明
- 复杂度棘轮不推高

## 不做

- 不收 Hello! Project 伞下的其他团（ADR-0021）
- 不区分「卒業」与「脱退」
- 不为身高/星座另找数据源
- 不新增档位（早安 49 人 > 40 档，40 档对它成立）
