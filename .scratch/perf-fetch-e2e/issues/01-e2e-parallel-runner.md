# 工单 01：E2E 并行 runner（`e2e:all`）

- **Status**: resolved
- **Blocked by**: 无

## 目标

新增 `npm run e2e:all`：并行跑四个套件（`e2e` / `e2e:v5` / `e2e:pwa` / `e2e:header`），
并发数**按可用内存决定**（≥6GB → 4；≥3GB → 2；否则串行），每条命令语义不变、仍可单独跑。

## 判据（可证伪）

1. 四套件在 runner 下全绿，且 **check 数与单跑一致**（245 / 54 / 43 / 72）。
2. ~~实测墙钟 **< 串行的一半**（串行基线 25 分钟，2026-10-05）~~ → **订正**（实测后改）：
   并行只能省掉「除最长套件以外」的时间，总墙钟 **≈ 最长套件**，不可能低于它。
   正确的判据是「总墙钟 ≈ 最长套件耗时（而不是四者之和）」——
   实测：串行 26 分钟（四者之和）→ 并行 **21m11s**（= e2e 自己的耗时）。
3. 内存不足时自动降并发：≥6GB → 4；≥3GB → 2；否则串行（**订正**：判据原写「2.5GB → 2」，
   与实现/spec 不符 —— 2.5GB 是串行档）。
4. 失败路径：让任一套件红 → runner **退出码非零**，并在结尾打印该套件的**尾部输出**
   （不交错四份原始输出）。
5. 四条既有命令行为不变（回归：各自单跑仍全绿）。

## 实现记录（2026-10-05）

**实现**：`e2e/run-all.cjs`（CommonJS，与 e2e/ 其他脚本一致）+ `npm run e2e:all`。

- `pickParallel(availMb)`：≥6000 → 4；≥3000 → 2；否则 1（读 /proc/meminfo，与
  `scripts/preflight.mjs` 同一口径）；`--max-parallel N` / `--only a,b` 可覆盖。
- 每套件输出**落日志文件** `/tmp/akb-e2e-logs/<name>.log`（卡住时能直接 `tail -f`
  看它卡在哪一步 —— 只在内存里缓冲的话，卡住的套件在结束前什么都看不到）。
- 失败聚合：结尾打印失败套件的尾部 25 行；退出码非零；不做自动重试。
- 自检：纯助手（pickParallel / tailLines / parseCounts / compareCounts）+ 真起一个
  失败进程验证失败路径（`--selftest`）。

**实测（2026-10-05）**：

| 运行                        | 并发             | 各套件耗时                                       | 总墙钟     |
| --------------------------- | ---------------- | ------------------------------------------------ | ---------- |
| 串行基线（22:45→23:11）     | 1                | —                                                | **26m**    |
| 全量（23:19 起）            | 2（可用 4570MB） | v5 32s / pwa 41s / header 4m15s / **e2e 21m11s** | **21m11s** |
| 子集 `--only v5,pwa,header` | 3                | v5 41s / pwa 54s / header 4m23s                  | 4m23s      |
| 工单 07 之后的全量          | 2                | e2e 3m12s / header 4m04s / pwa 37s / v5 31s      | **5m12s**  |

四套件全部 check 数守恒且绿（245 / 54 / 43 / 72）。

**真跑抓出来的 bug（已修 + 自检覆盖）**：`runOne` 改成通用签名后不再 spread `suite`，
`expect` 丢失 → 4/4 全过却打了 4 条「与基线不符」⚠。把比较抽成纯函数 `compareCounts`
并补了 4 条自检断言。

**结论（重要，交给下一轮决策）**：主套件 `e2e.cjs` 自己就是 21 分钟 —— 并行把
「四者之和 26 分钟」压到「最长套件 21 分钟」，但**不可能再低**。要让全量 ≤5 分钟，
必须动主套件本身（拆块 / 砍单检查成本），那是另一张工单。

## 注意

- 端口已隔离（8765/8777/8781/8861）；pwa 写自己的 tmp 目录，不冲突。
- 复用 `scripts/preflight.mjs` 的读数口径（它已经会报可用内存与遗留服务器）。
- 不要给 runner 加「自动重试」（会掩盖 flake —— 本项目的 flake 有前科，要看见它）。
- 每套件的输出**重定向到文件**，结束行打印「套件 / check 数 / 耗时 / 结论」。
