# 工单 01：E2E 并行 runner（`e2e:all`）

- **Status**: ready-for-agent
- **Blocked by**: 无

## 目标

新增 `npm run e2e:all`：并行跑四个套件（`e2e` / `e2e:v5` / `e2e:pwa` / `e2e:header`），
并发数**按可用内存决定**（≥6GB → 4；≥3GB → 2；否则串行），每条命令语义不变、仍可单独跑。

## 判据（可证伪）

1. 四套件在 runner 下全绿，且 **check 数与单跑一致**（245 / 54 / 43 / 72）。
2. 实测墙钟 **< 串行的一半**（串行基线 25 分钟，2026-10-05）。
3. 内存不足时自动降并发：注入「可用 2.5GB」的读数 → 并发数 2；「1.5GB」→ 串行。
4. 失败路径：让任一套件红 → runner **退出码非零**，并在结尾打印该套件的**尾部输出**
   （不交错四份原始输出）。
5. 四条既有命令行为不变（回归：各自单跑仍全绿）。

## 注意

- 端口已隔离（8765/8777/8781/8861）；pwa 写自己的 tmp 目录，不冲突。
- 复用 `scripts/preflight.mjs` 的读数口径（它已经会报可用内存与遗留服务器）。
- 不要给 runner 加「自动重试」（会掩盖 flake —— 本项目的 flake 有前科，要看见它）。
- 每套件的输出**重定向到文件**，结束行打印「套件 / check 数 / 耗时 / 结论」。
