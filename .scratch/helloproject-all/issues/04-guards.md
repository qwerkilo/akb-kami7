## 内容

这一单**预期几乎不改产品代码** —— 机制都已就位，要做的是**验证它们对 11 团成立**，
不成立才改：

1. **团体下拉 11 项**：`refreshGroupOptions` 从段派生，应自动；验证顺序与团名。
2. **期生按团隐藏（决定 4）**：`generationOptions(sections, groupFilter)` 已按团算、
   空则 `#gen-field` 不出现 —— 验证：切到 アンジュルム/Juice=Juice/… 控件不出现，
   切回 モーニング娘。出现且仍是 18 期。
3. **身高按团**：有的团列里有 `身長`（Juice=Juice 现役在合并列里、つばき/BEYOOOOONDS/
   OCHA/ロージー有独立列）→ `bio.height` 有则显示；**不要为了统一去编数据**。
4. **跨系列重名守卫**（缝③/②）：新增 112 人后重跑；已知真实世界同名要放行，
   判据仍是「**现役**不得跨系列重复」。
5. **i18n**：本批**不加 UI 文案**（团名是数据）—— 若实现中发现要加，三语齐。

## 验收

- 主 E2E + v5 + PWA 三套跑完，红项逐条定性（既有 vs 新）。
- 仓外探针：11 团 × 期生控件（至少 モーニング娘。有 / 其余无）、团体下拉 11 项、
  至少一个团的资料卡显示身高。
- 变异 ≥4 个全红（至少含：期生控件不按团隐藏、团体下拉漏团、身高不显示）。
- 检查点：本轮基点、范围、结论、遗留。
- `npm run check` 退出码 0；复杂度棘轮未推高。
