- **Blocked by**: —

## 内容

把 `scripts/morningmusume_members.py` 的按团配置扩到 11 团。每团需要：
**段标题**（现役段 / 毕业段的真实标题）、**状态规则**、**列名归一**。

各团实测差异（对着真实 wikitext 做，别照抄）：

| 团                   | 现役段         | 毕业段                                                      | 已知坑                                                   |
| -------------------- | -------------- | ----------------------------------------------------------- | -------------------------------------------------------- |
| アンジュルム         | 現在のメンバー | 元メンバー                                                  | `加入年月日（加入期）` 合并列（期生不解析）              |
| Juice=Juice          | 現在のメンバー | 元メンバー                                                  | **现役把「血液型/身長/出身地」塞一列**；毕业段列名又不同 |
| つばきファクトリー   | 現在のメンバー | 元メンバー                                                  | 脏列名 `血液型]]`、`na}}`、`[[…                          | …]]` |
| BEYOOOOONDS          | メンバー一覧   | （无）                                                      | **首列是「所属」、名前在第二列**                         |
| OCHA NORMA           | 現在のメンバー | 元メンバー                                                  | 脏列名 `血液型]]`、`研修生]]出身`                        |
| ロージークロニクル   | メンバー       | （无）                                                      | —                                                        |
| Berryz工房           | （无现役）     | 無期限活動休止発表時のメンバー / 過去に在籍していたメンバー | 全员 former                                              |
| カントリー・ガールズ | （无现役）     | 活動休止時のメンバー / 過去に在籍していたメンバー           | 全员 former                                              |
| こぶしファクトリー   | （无现役）     | 解散時のメンバー / 旧メンバー                               | 全员 former                                              |

列名归一的扩展要能吃掉 `]]`、`[[A|B]]`、`<small>…</small>`、`'''…'''` 这些残留
（℃-ute 批已有 `_strip_refs`/`_header_name`，扩它们而不是新写）。

**不解析**「加入期」→ 成员的 `generation` 一律空串（决定 4）。

## 验收

- 每团一条 fixture 驱动的红测试（从真实 wikitext 切片，别手编表格）；
  至少覆盖：アンジュルム 9+17、Juice=Juice 11+8、つばき 11+6、BEYOOOOONDS 11、
  OCHA 8+2、ロージー 9、Berryz 7+1、カントリー 4+4、こぶし 5+3。
- 三个停止活动团**全员 former**；现役团第一段全员 current。
- 每团断言 `generation == ""`。
- 变异 ≥4 个全红（至少含：BEYOOOOONDS 的名前取错列、Juice=Juice 合并列不拆、
  停止活动团 status 推导错、脏列名不归一）。
- `npm test` 的 Python 全绿；本工单只动 Python 与 fixture，不跑 E2E。
