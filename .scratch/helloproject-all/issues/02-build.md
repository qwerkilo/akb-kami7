# 02 · 装配：11 团 + 跨团合并 + 照片

- **Status**: ready-for-agent
- **Blocked by**: 01
- **所属 spec**：`.scratch/helloproject-all/spec.md`
- **缝**：①（解析/装配纯函数）/ ③（产物不变量）

## 内容

1. **`build_members` 扩到 11 团**，`build_sections` 的 `GROUPS` 顺序稳定
   （产物可断言）；段 label = 团名（早安批的既有形状）。
2. **跨团合并（决定 2）**：同一人（按 `norm_name` 归一）在同系列只留一份，
   保留**最近归属** —— 现役优先；都非现役取毕业日较晚者。实测 4 人：
   船木結、井上玲音、梁川奈々美、稲場愛香。合并要**在装配处**（`build_members`）
   做，不要留给 UI —— 否则产物里就有两份、下游每处都要记得去重。
3. **状态（决定 3）**：Berryz工房 / カントリー・ガールズ / こぶしファクトリー
   全员 `former`；现役六团第一段 `current`、其余段 `former`。
4. **照片**：现役六团走官网列表页（`parse_list` 的 hello-project 形状，
   6 个 slug 已知）→ `urls[file_key]`；停止活动团与毕业者走 Commons
   （复用 `photo_chain.commons_photo`）。取不到照旧 warn + 占位。
5. **产物守卫（缝③）**：11 段、段顺序、每团人数区间（区间不是精确值，
   上游会动）、4 个合并者**各只出现一次**、停止活动团全员 former、
   `generation` 全空、字段缺失是常态（各团列不同 → 不许要求字段齐）。

## 验收

- 红测试：合并 4 人（构造「现役在 B 团、毕业在 A 团」的夹具，断言只留 B）、
  停止活动团 status、产物段数与顺序、合并者只出现一次。
- 产物测试人数区间要对（例如 アンジュルム 26±、Juice=Juice 19±，按实测上下浮动）；
  **别写精确值**（上游会动），也别宽到「≥0」那种恒真。
- 变异 ≥4 个全红（至少含：合并方向反了、停止活动团给 current、
  重复不合并、段顺序按字典序）。
- `npm run check` 退出码 0。
