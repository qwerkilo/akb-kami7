# Spec：可分享的排名链接

- **Status**: done
- **依据**：2026-10-29 grilling（Q1–Q6 全采纳推荐）

## 问题

结果页「分享到 X」只带站点首页 URL，接收者看不到分享者的排名；海报只能截图传递。

## 决策

- **承载**：最终排名（有序成员 id）+ 系列 + 档位 + 标题。不编码对决答案（与算法版本耦合）。
- **接收者**：只读结果页（榜单 + 海报 + 标题）+ 「这是分享的排名」说明 + CTA「我也来排」；
  **不写入**接收者的 localStorage / session。
- **入口**：结果操作区新增「复制链接」；X 分享串自动带该链接。
- **URL**：`?r=<系列>-<档位>-<id,id,…>&t=<标题>`（query，可读；40 档约 480 字符）。
- **校验**：core 校验语法（系列已知、档位 ∈ {7,16,40}、id 数 == 档位、id 形状、不重复）；
  app 再校验成员归属该系列；任一失败 → 静默忽略、正常进首页。
- **降级**：离线打开时名字可读、缺 full 图走占位；复制失败给 toast。

## 验收

- `core.encodeShare/decodeShare` roundtrip + 5 类非法输入（缝②）。
- E2E：打开 `?r=` → 顺序/标题正确、只读说明可见；CTA 回挑人页且 URL 清理；复制按钮写入含 `?r=` 的链接；
  非法链接被忽略。
- i18n 五键 ×3 语言。

## 审查修订（2026-10-29，两轴审查后）

- **高-1 已修**：只读页点 CTA 曾走「结果页返回」= `abandon`，会清掉接收者自己的对决存档。
  `exitShared()` 先把 `view` 归位 `pick`；E2E 种一个接收者进行中的对决，断言打开分享与
  CTA 前后存档**逐字节不变**。变异（去掉 `view="pick"`）被杀。
- **高-2 已修**：切语言/切皮肤触发 `renderAll → paint` 时曾渲染接收者自己的结果/对决。
  `paint()` 优先 `paintSharedView()`；结果相关命名统一走 `activeSeries()/activeSize()`；
  E2E 断言切 en 后（`htmlLang === "en"`）榜单/标题/说明仍属分享。变异（关掉 paint 分支）被杀。
- **中-1/中-2**：页头品牌与系列 tab 跟随分享系列；样式/皮肤切换用共享上下文（`names()` 单一出处）。
- **中-3/中-4**：复制断言改为解析 `r` 三段并逐 id 比对顺序；补接收者存档与跨系列夹具。
- **低-1…低-7**：`Object.hasOwn` 防原型键；当前步不可点；退出恢复标题；URL 保留字面逗号；
  标题上限与 `index.html` maxlength 互钉；E2E 用计算样式/`waitFor`，补复制失败、40 档、X 串；
  SW 不缓存带 query 的导航（分享链接不再积压 index.html 副本）。

**未直接覆盖（如实）**：画布里的 hashtag/文件名由 `activeSeries()` 单一出处保证，E2E 无法读画布文本；
离线打开 `?r=` 未进 E2E（SW 规则有守卫，行为用例待补）。
