# spec · 把 ℃-ute 并入早安系列

- **状态**：已定稿（2026-10-02，两轮 grill 后）
- **关联**：`.scratch/morningmusume/spec.md`（早安那一批的前作）、ADR-0021（系列边界，本次有修订）
- **一句话**：早安系列从「一个团」变成「两个团」，其中第二个团已经解散 8 年，
  于是我们第一次在系列内处理**没有官网、字段不一致、照片几乎拿不到**的团体。

## 背景与已备事实

- **℃-ute**：2005–2017 活动，**2017 年解散**。ja.wikipedia 有独立条目，
  表格结构与モーニング娘。**完全同形**（含 `rowspan`、`{{Display none|…/}}` 假名块、
  脚注嵌套）—— 所以**工单 01 的解析器可直接复用**，不重写。
- **规模**：约 24 人（5 名「解散时成员」+ ~19 名「过去在籍过」）。全系列 51 → ~75 人。
- **字段不一致**（必须当成常态处理，不是意外）：

  | 字段     | モーニング娘。 | ℃-ute                                               |
  | -------- | -------------- | --------------------------------------------------- |
  | 期生     | 有（18 期）    | **没有**                                            |
  | 身長     | **没有**       | 有                                                  |
  | 毕业日   | 有             | 有                                                  |
  | 官网照片 | 有             | **无官网**（团已解散，官网首页 7 个现役团里没有它） |

- **照片预期**：新增 ~24 人**全部依赖 Commons/Wayback**，
  而モーニング娘。的毕业成员 Commons 命中率实测 **27%** → 预计℃-ute **< 10%**。

## 已采纳的八条决定

1. **系列改名**：早安少女家族 / Morning Musume / モーニング娘。 →
   **早安家族 / Hello! Project / ハロー!プロジェクト**；tab 短标签
   **早安 / HP / ハロー**。
2. **期生筛选按团隐藏**：切到℃-ute 时隐藏该下拉（控件在、选了没用是最糟的）。
3. **身長「有就显示、没有就不占位」**：资料卡少一行可以，造假值不行。
4. **7 档沿用「推し7」**：概念对两个团都成立；等爱也叫推し7，改名会撞。
5. **已解散的同级团体仍属该系列**（ADR-0021 修订，隐含条款第一次显式化）。
6. **不收伞**：伞下 6 个现役团与モーニング娘。的 11 名现役**完全重叠**，
   本站对重叠**不会报错** —— 结论不变，只是它挡的是现役团。
7. **照片缺口只出名单、不承诺修**：像모ーニング娘。的 24 人一样逐个点名记账。
8. **官网 slug 不再去找**：团已解散，没有官网页面（此前猜的路径全 404）。

## 不做什么

- 不为℃-ute 写散文解析器（另外 5 个团要，那是一张独立工单）。
- 不把身高/星座补到モーニング娘。（两个源都没有）。
- 不动 `core.js` 的 `SERIES_KEYS` 结构（第四个键已经在了）。

## 整体验收

- `npm run check` 退出码 0
- 三套 E2E 全绿（回归 / v5 / PWA），且「切到早安系列」的流程**两个团都覆盖**
- 复杂度棘轮未推高
- **照片缺口名单写进工单**：抓到几个人、名字、哪几级回退失败
- 跨系列重名守卫仍然绿（℃-ute 的人与早安/48G/等爱都不重叠 —— 这本身要被验证）
