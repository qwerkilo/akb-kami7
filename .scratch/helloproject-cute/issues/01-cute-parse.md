## 内容

现在的 `parse_wiki_members` 把节标记写死成モーニング娘。的
`=== メンバー ===` / `=== 過去のメンバー ===`，而℃-ute 的条目是
`== メンバー ==` / `=== 解散時のメンバー ===` / `=== 過去に在籍していたメンバー ===`
（**两个毕业节**，不是一个）✓ 实测：后者有 `卒業・脱退日卒業公演会場` 列 ✓
而「解散时」那节**没有该列** ✓ —— 于是「解散时成员」的毕业日**取不到** ✓
（那 5 人本来就已在解散时全员退出 ✓ 站点需要的是「毕业/退团年」✓ 这一列的缺失要显式处理 ✓ 不许静默给空 ✓）。

1. 把节标记与「哪个节产出 current、哪个产出 former」收成**按团的配置**
   （`GROUPS = {"モーニング娘。": {...}, "℃-ute": {...}}`）✓ 不堆第三个布尔 ✓
2. `parse_wiki_members` 的 `status` 仍由「出现在哪个节」决定 ✓ **不引入第三个状态值** ✓
   （℃-ute 全员毕业 ✓ 包括那 5 名「解散时成员」✓ —— 见工单 02 的断言 ✓）
3. **fixture 从真实 wikitext 切**：`scripts/fixtures/morningmusume/`（与前作同目录 ✓
   该目录已在 `.prettierignore` 里 ✓ 真数据必须逐字保持 ✓）
4. 身高**不进 bio**（决定 3：有就显示 ✓ 但**落哪个键**要定 —— 见下）
   → 我倾向落 `bio.height` ✓ 因为站内身高只出现在资料卡 ✓ 与血型/出身地同一层 ✓
