# Spec：首屏矩阵入仓（第五轮扫描候选 5）

- Status: resolved（40 档的托盘发现另议 —— 见下）
- 来源：第五轮架构扫描候选 5 ——「P0 宽度矩阵只活在 /tmp/opencode，仓内注释还写着 54 状态（实为 72）」

## 核查结果（先核事实，能就地关闭就关闭）

| 扫描的说法             | 核查                                                                                                                                                                                                   |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 完整矩阵只活在 /tmp    | **一半不成立**：语言 × 档位 × 系列 × 在线/离线（72 状态）已在仓内 `e2e/verify-header.cjs` ✓                                                                                                            |
| 仓内注释还写着 54 状态 | **成立**：`e2e/e2e.cjs:1618` 指着 `/tmp/opencode/verify-header.cjs`（54 状态）→ 已改成 `npm run e2e:header`（不抄数字）                                                                                |
| 宽度矩阵               | **成立且没得关**：`e2e/e2e.cjs:1631` 指着 `/tmp/opencode/verify-first-screen.cjs`（2 皮肤 × 3 语言 × 320/360/375/390/414/560 = 36 状态），那个脚本**已经没了**（/tmp 换会话即丢），仓内只有 390px 一档 |

## 决定

把宽度矩阵收进仓：新建 `e2e/verify-first-screen.cjs`（36 状态，后加档位维到 72）+ `npm run e2e:first` +
进 `run-all`（`expect: 72` —— 每状态两条检查）+ 守卫（有 `createChecker` 的套件必须进 run-all）。

判据与主套件 390px 块**同源**：

1. **托盘之上完整可见的脸 ≥ 一整行的列数**（不是像素阈值）；
2. 无横向滚动。

档位维取**两端**（7 / 40）：40 档的托盘槽位最多，曾是「空槽位换行 → 托盘 244px →
首屏 0 张脸」的最坏档（本批发现、用户拍板修掉，见工单 02）；修成单行横向滚动后
它必须与 7 档一样过。

## 验收（可证伪）

1. `npm run e2e:first` **72 状态 × 2 检查 = 144/144**（档位维 7 / 40 两端）。
2. `npm run e2e:all` 5 套件全绿（新的 `first` 套件在列；实测 245/54/43/72/144）。
3. 守卫：把 `first` 从 `run-all` 删掉 → 测试红（变异被杀）。
4. 陈旧指针修掉：`e2e/*.cjs` 里不再有指向 `/tmp` 的**活**指针（只剩解释历史的注释）。
