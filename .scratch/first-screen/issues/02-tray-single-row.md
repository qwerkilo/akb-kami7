# 工单 02：托盘槽位改单行横向滚动（40 档不再盖住首屏）

- **Status**: resolved
- **Blocked by**: 无（工单 01 的矩阵先落，用来证明修复）

## 问题（工单 01 的矩阵核出来的）

托盘里的 `#slots` 是 `repeat(7/8, 1fr)` 网格 → **16/40 档的槽位换行**：
7 档 1 行 37px；16 档 130px；**40 档 182px（5 行）、托盘总高 244px**。
390px 下托盘顶 600px、第一行卡底 617px → **「首屏完整可见的脸」= 0 张**
（7/16 档都成立）。这是设计取舍（空槽位 = 目标进度的可视表达），
但它在手机上吃掉了整个首屏。

## 决定（用户拍板）

**A：`#slots` 改单行横向滚动** —— 不换行、`overflow-x: auto`，槽位宽度取
「7 档塞满托盘」时的宽度（`calc((100% - 6 * 8px) / 7)`），档位再大也只横滑；
7 档外观不变、所有槽位仍可达。

## 实现

- `style.css`：`.slots` 由 grid 改 flex（`gap: 8px` 保留）+ `overflow-x: auto` +
  `scrollbar-width: none`（`::-webkit-scrollbar` 同步隐藏）；`.slot` 加
  `flex: 0 0 calc((100% - 6 * 8px) / 7)`。
- 退役：`.tray.wide .slots`（8 列规则）与 `--slots` 自定义属性 —— 网格没了，两者
  都成了死代码，`app.js` 的 `renderTray` 相应删掉那两行。

## 判据与结果

| 项                           | 修前                                 | 修后                     |
| ---------------------------- | ------------------------------------ | ------------------------ |
| 托盘高（390px）              | 7 档 101 / 16 档 130 / **40 档 244** | 101 / **97** / **97**    |
| 首屏完整可见（40 档，390px） | **0 张**                             | **3 张** ✓               |
| 7 档槽位高                   | 37px                                 | 38px（布局模式差异 1px） |

- 探针：`/tmp/opencode/probe-40.cjs`（7/16/40 × 390px）与 `probe-tray.cjs`（托盘高）。
- `first` 套件加**档位维**（7 / 40 两端 —— 40 档是槽位最多的最坏档）：
  2 皮肤 × 3 语言 × 6 宽度 × 2 档 = **72 状态 × 2 检查 = 144**。
