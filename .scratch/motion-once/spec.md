# 「动一次，然后保证它一定停下来」合一处

## 问题

`app.js` 里这句话是三份独立实现，各带一个魔数与一条源码正则守卫：

| 位置                         | 机制                                      | 兜底 |
| ---------------------------- | ----------------------------------------- | ---- |
| `show()` 的切屏转场          | class + `animationend` + `ev.target` 判据 | 400  |
| `rosterEntered()` 的 stagger | **只有定时器**（无事件）                  | 600  |
| `unveil()` 的揭幕            | 克隆层 + `transitionend`                  | 700  |

**已坐实的缺陷**（在 `clear` 里挂日志实测）：
`clear()` 先在 **+714ms** 被一张卡的 `cardIn` 事件调用（`ev.target !== shown` → 判据挡回），
再在 **+756ms** 被兜底定时器调用。也就是说 **`{ once: true }` 被子元素冒泡上来的事件消耗掉**，
相位自己的 `phaseIn` 事件**永远等不到监听器** —— 那条判据被装它的 `{once:true}` 自我击败，
清理永远退化成定时器。

## 决定（grill 2026-10-01）

1. **三处合一**成 `playOnce(el, cls, kind, opts)`，**自己解绑**（不用 `{once:true}`）：
   事件与定时器两条路都保证清理；`unveil` 那种「结束时要移除克隆层」的用 `onDone`。
2. **兜底时长从 CSS 实际时长读出**：元素（或指定取样选择器）的
   `animation-duration + animation-delay` 最大值 **+ 一个统一余量**。
   取样选择器是必需的 —— 名册的动画挂在 `.card` 上，挂在 `.roster` 上读出来是 0。
3. **`show()` 不拆**，只把「播一次」那段抽出去；跨函数的调用顺序约定写进注释。

## 等价性要求

三个时刻的**实际时长**在改前改后落在同一量级（相位转场、名册 stagger、结果页揭幕），
两个皮肤 × 降级开关都要量；降级下三个时刻都不播且不残留类。

## 不做

- 不改 `show()` 的相位/chrome/揭幕复位职责划分。
- 不动 CSS 的时长令牌本身。
