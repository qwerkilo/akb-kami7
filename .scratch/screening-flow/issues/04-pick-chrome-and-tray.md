## 内容

- **页头** ≤56px：品牌 + 系列 + 「⋯」收成一行；语言/皮肤进「更多」浮层
  （档位留在挑人步 —— 品牌 79 + 系列 201 + ⋯ 44 = 324 装得下，但再加档位 211
  就是 535 > 390 装不下）
- **托盘** ≈72px：槽位 `max-height` 88 → 54px、内边距 12 → 8px
- **名次角标** 从右上挪到左上（「i」的 44px 命中盒占着右上）

实测（390×844，classic / sticker 两款皮肤）：

| 部位         | 改前        | 改后        |
| ------------ | ----------- | ----------- |
| 页头         | 209 / 245px | 66 / 60px   |
| 首张卡片顶边 | 763 / 811px | 620 / 626px |
| 托盘         | 90 / 93px   | 81 / 84px   |

## 涉及缝

- ⑦ E2E：`openMore` / `setSkin` / `setLang` 三个助手（切皮肤/语言要先开浮层）

## 备注

- **抓到两个真 bug**（都只有 E2E 抓得到，`app.js` 没有单测缝）：
  ① 「更多」浮层 `z-index: 20` 低于 sticky 步骤条的 70 → 真机上浮层被盖住，
  点语言实际点到步骤条上（已提到 90）
  ② `[hidden]` 被作者样式里的 `display` 盖掉（`.masthead`/`.steps` 都有 display）
  → 顶部加了一条全局规则钉死。同一个坑在工单 03 踩过一次。
