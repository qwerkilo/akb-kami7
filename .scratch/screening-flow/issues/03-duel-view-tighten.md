  所以大部分 E2E 断言不用改 ✓ ✓。

  页面文档高度从 1350px → **844px = 视口高** ✓✓（**整页不再需要滚动** ✓）。

  试过 `align-items: stretch` ✗ —— 卡片被拉成 637px 的空壳（照片定比例、其余全空白 ✓✗），
  回到 `center` + 定行数 ✓ ✓。
- **同一个坑踩了两次（如实记账）**：作者样式里的 `display`（`.masthead` / `.steps` /
  `#phase-duel` 都有）会盖掉 UA 样式表的 `[hidden] { display: none }` ✓✗。第一次只给
  `#phase-duel` 加了 `:not([hidden])` ✓；第二次页头/步骤条又中招 —— 我的探针当时量的是
  `el.hidden` **属性**（true ✓）而不是**计算样式**（仍是 flex ✗），所以看起来对、截图不对 ✓✗。
  已在 `style.css` 顶部加一条 `[hidden] { display: none !important; }` 一次性钉死 ✓ ✓。
