# 03-duel-view-tighten · 对决页收紧

- **Status**: done
- **所属 spec**：`.scratch/screening-flow/spec.md`
- **依据**：`docs/adr/0019-screening-then-rank.md`

## 内容

页头与步骤条在页内滚动 —— 对决页要滚 2.2 屏才看得到那两张脸。收成一条细进度条
（题数 + 进度 + 剩余），两张脸垂直居中，撤回/保存常驻底部。实测 390×844：
文档高 1350 → 844 = 视口高（整页不用滚），两张脸顶边 840 → 298。

细条复用既有 `duel-step` / `duel-max` / `duel-bar` / `duel-extra` id，所以多数 E2E
断言一行没改。

## 涉及缝

- ⑦ E2E：`goToPick` 助手（对决页收起页头/步骤条/页脚，测试要回挑人页得走页内出口）

## 备注

- 已知取舍：步骤条收起 = 对决中不能点 ①/③。功能没丢（页内「保存并返回」是同一件事），
  已在 ADR-0019 与工单记录里说明。
- 两张脸因 meta 行数不同仍可能差 ~20px 高（内容差异，未强行拉齐）。
