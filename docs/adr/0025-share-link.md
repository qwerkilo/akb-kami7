# ADR-0025：可分享的排名链接

- 状态：已采纳（2026-10-29）

## 决策

分享链接编码**最终排名**（有序成员 id）+ 系列 + 档位 + 标题，查询参数形如
`?r=<系列>-<档位>-<id,id,…>&t=<标题>`；打开后进入**只读结果页**，不写入接收者存档。

## 理由

- 编码排名而非对决答案：答案与 `replayTiers` 的算法/题库版本耦合，改版后旧链接会重放出不同结果。
- 查询参数而非 hash/base64：可读、可手动检查；40 档约 480 字符，远低于常见 URL 上限。
- 只读：分享者的进度不能覆盖接收者未完成的对决；接收者要参与就走「我也来排」。

## 边界

- core 只做语法校验；成员归属（id 属于该系列）由 app 用 `BY_ID` 校验。
- 坏链接静默降级到首页；不展示错误页。
- 离线打开：名字可读，未缓存的 full 图走占位。
