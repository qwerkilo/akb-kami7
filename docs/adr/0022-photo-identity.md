# ADR-0022 · 照片身份判定：三条证据 + 在籍期校验

- 状态：已采纳（2026-10-03）
- 关联：ADR-0021（系列边界）、`docs/agents/data-pipeline.md`、`CONTEXT.md`（照片回退链 / 在籍期校验）
- 依据：早安家族照片缺口（75 人）的三问 grilling 与外部源调研（2026-10-03）

## 背景

给早安家族的毕业者补照片时，最富的源是**旧官网的 Wayback 快照**（覆盖 ~66/75），
但旧官网用**扁平文件名**：`berryz/img/isimura.jpg`、`images/artist_photo/cute01_s.jpg`、
`og/<romaji>_s.jpg`。同一个文件名在不同年份指向**不同的人**（阵容更替后新图覆盖旧路径），
所以「按文件名/序号认人」会张冠李戴 —— 把别人的脸放到成员档案上，比占位卡更糟：
它是**看起来正确的错误**，用户不会发现，海报会被分享出去。

## 决定

一条命中必须满足**三条证据之一**：

1. 页面或 `alt` 里有该成员姓名；
2. 文件名是**罗马字姓名**且能对应到该成员；
3. 序号图（`cute01`）靠「该页 `alt` 顺序 + 该团在籍名单」映射。

**三条都追加同一前提：Wayback 捕获时间戳落在该成员的在籍期内**
（`join` ≤ 捕获时间 ≤ `end`；`end` 缺失时用该团的终止年份）。

配套：

- 全落空 → 占位卡 + **缺图名单显式记录**（有守卫钉住只许减），不伪造、不用非肖像图。
- 现官网 `/og/` 源不受此限（它是当前页面，无时间戳问题），但它的姓名来自 `nameJa`/`alt`，
  仍走证据①。

## 后果

- 覆盖率低于「不校验」的做法：部分成员会因缺在籍期或快照越界而留在缺图名单 —— 接受。
- 需要成员的在籍期数据（`join`/`end`/团终止年份）—— 这些字段已经在产物里。
- 新增源（未来）必须复用同一判定，不得为提升覆盖率放宽本规则。
