# 范围：国内 48 Group 六团 + SDN48，不含海外团

需求原文是「扩展至 48group 所有成员」。48pedia 上海外姐妹团（JKT48、BNK48、MNL48、CGM48、KLP48 等）也有成员列表，但姓名体系为拉丁字母、页面模板与国内团存在差异（如部分行无 ルビ、无加入期或无照片）；SNH48 系 2016 年已独立，不属 48 Group。决定本版纳入 AKB48、SKE48、NMB48、HKT48、NGT48、STU48、SDN48（共约 1180 人），海外团不纳入——先保证国内部分的数据质量与解析一致性，海外团如后续要加，再单独评估。

## Considered Options

- 含海外现行团与历史团：人数几乎翻倍，但需为拉丁名、混合模板、缺图做额外兜底
- 含 SNH48 系（BEJ48/GNZ48 等）：其已独立于 48 Group，超出「48group」官方谱系
