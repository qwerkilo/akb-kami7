# ADR-0011：皮肤系统（原版默认、页头切换、海报跟随）

日期：2026-09-27

## 背景

上游原版（Casmeter/akb-kami7，`11fa090`）是浅灰白卡风格；本项目 v2/v3 演化出贴纸风。用户希望保留原版观感，并与现行风格作为**皮肤**切换。

## 决定

1. **两款皮肤**：`classic`（原版，**默认**）与 `sticker`（本项目现行）。
2. **主题层实现**：同一 DOM，两套 CSS 令牌与组件样式（`html[data-skin]`）；新功能控件（系列 tab、32 档、资料卡、清空）按各皮肤语言补样式，**不维护两套结构**。
3. **切换器**：页头（中/EN 语言按钮旁）「原版 | 贴纸」胶囊（原型 A，`prototype/ui-v4-skins` @ `d0acb5c`）；选择存 localStorage，全设备一份、与系列无关。
4. **海报跟随皮肤**：导出海报的令牌随当前皮肤——classic 用上游 `11fa090` 的调色（`#edeff3` 底、无卡片描边、`#f4c20d` 黄带），sticker 用现行贴纸调色（奶油底、3px 墨描边、柠檬带）。
5. 资料卡、对决页、结果页等全部界面元素跟随皮肤。

## 后果

- 海报令牌新增 `cardStroke`（classic 0 / sticker 3）；`poster.js` 的 `slotCard` 按此描边。
- 无存储的旧用户默认看到原版（与上游一致）。
- E2E 需覆盖：页头切换、刷新持久化、海报底色像素随皮肤变化。

## 窄屏页头（2026-09-29 补记）

工单 04 让页头在 ≤560px 收成一行（品牌 + 系列 tab + 「更多」，语言/皮肤进浮层）。三个约束
互相挤压，横账必须写下来：

- 内容宽 358 = 品牌 + gap 8 + 系列 tab + gap 8 + 「更多」52。
- **品牌随系列变宽**：神7 79 / 7福神 123 / 推し 7 132。
- 系列 tab 满宽随语言变：zh 201 / en 254（=LOVE Family）/ ja 212（イコノイジョイ）。

所以 tab 的预算只有 158，三语都超 → 第三个 tab 被压成滚动盒、被切掉，「更多」又盖在
上面（`elementFromPoint` 命中 `more-btn`）→ 等爱在手机上点不到。两条决策：

1. **窄屏隐藏副标题「历代成员版」**（眉标本就隐藏，它是补充说明）让出一行。
2. **系列 tab 有长短两个标签**（`core.names()` 的 `seriesShort` ← i18n `series_*_short`；
   `app.js` 渲染成两个 `<span>`，CSS 按断点选）。按钮里必须有两个 span —— 直接写
   `textContent` 会把结构抹掉，窄屏就只剩截断的长标签。内边距同时 12→8px。
   ja 最紧时 132+8+157+8+52+32 = 389 ≤ 390，所以**不动品牌字号**（品牌是辨识度，
   不该为导航让路）。≤380px 时系列 tab 另起一行（头部变高，好过切掉半个 tab）。

守卫：E2E 在 390px 下**逐语言 × 逐系列**断言每个 tab 点得到 / 不出视口 / 不被「更多」
压住 / 同行不换行。只量初始的 48g + 中文会漏 —— 那正是这个 bug 溜过去的原因。
