# ADR-0011：皮肤系统（原版默认、页头切换、海报跟随）

日期：2026-09-27

## 背景

上游原版（Casmeter/akb-kami7，`11fa090`）是浅灰白卡风格；本项目 v2/v3 演化出贴纸风。用户希望保留原版观感，并与现行风格作为**皮肤**切换。

## 决定

1. **两款皮肤**：`classic`（原版，**默认**）与 `sticker`（本项目现行）。
2. **主题层实现**：同一 DOM，两套 CSS 令牌与组件样式（`html[data-skin]`）；新功能控件（系列 tab、32 档、资料卡、清空）按各皮肤语言补样式，**不维护两套结构**。
3. **切换器**：页头（中/EN 语言按钮旁）「原版 | 贴纸」胶囊（原型 A，`prototype/ui-v4-skins` @ `d0acb5c`）；选择存 localStorage，全设备一份、与系列无关。
4. **海报跟随皮肤**：导出海报的令牌随当前皮肤——classic 用上游 `11fa090` 的调色（`#edeff3` 底、无卡片描边、`#f4c20d` 黄带），sticker 用现行贴纸调色（奶油底、3px 墨描边、柠檬带）。
5. 资料卡、对决页、结果页等全部界面元素跟随皮肤。

## 后果

- 海报令牌新增 `cardStroke`（classic 0 / sticker 3）；`poster.js` 的 `slotCard` 按此描边。
- 无存储的旧用户默认看到原版（与上游一致）。
- E2E 需覆盖：页头切换、刷新持久化、海报底色像素随皮肤变化。
