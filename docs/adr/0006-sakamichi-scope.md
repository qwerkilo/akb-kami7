# 坂道系列纳三团，排除吉本坂46 与坂道研修生；历史成员并入现团

坂道系列纳入乃木坂46、櫻坂46、日向坂46（约 205 人，含历史成员）。欅坂46、けやき坂46 是现团前身，不单独成团：欅坂46 成员列在櫻坂46 页面、けやき坂46 成员列在日向坂46 页面，按现有跨团去重规则合并（如長濱ねる同时出现在两页）。排除吉本坂46（搞笑艺人组合，与偶像系不符）与坂道研修生（研修计划，无加入期数据，多数与入团后重复）。

## Consequences

- 坂道成员沿用与 48G 相同的成员模型：团体、期生、现役/毕业、跨团去重、无照片占位。
- 与 ADR-0001 的关系：0001 排除了 48G 的海外团；坂道三团是新增系列，不改变 0001 的决定。
