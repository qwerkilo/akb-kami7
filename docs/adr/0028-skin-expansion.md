# ADR-0028：皮肤扩展（玻璃花园 / 青瓷 / 珍珠 + 官方 A+C）

- **状态**：accepted（2026-11-01）
- **背景**：视觉批次后官方皮肤仍是三款（akb / classic / sticker）；原型实验中
  用户选定「玻璃花园 + 青瓷 + 珍珠」三套新皮肤，并要求官方皮肤合并
  A「应援带」与 C「生写卡」两个方向。
- **决定**：
  1. 皮肤集合扩为六款：`akb`（默认，官方 A+C）、`classic`、`sticker`、
     `glass`、`celadon`、`pearl`。
  2. 官方 `akb` 改为 A+C：粉色斜向应援带、方形粉框卡片、粉色名字条、
     票根式选中序号与方形按钮；白底/官方粉不变。
  3. 三套新皮肤各用一套完整令牌块（键集与其他皮肤相同）：
     - glass：薰衣草/薄荷渐变 + 玻璃拟态 + 紫色主色；
     - celadon：淡青灰 + 墨绿 + 细框留白；
     - pearl：暖象牙 + 香槟金 + 拱形照片。
  4. 三套新皮肤只改变视觉层，不改变会话/筛选/对决/海报语义；海报跟随令牌。
- **代价**：首屏矩阵从 217 条增至 433 条（6 皮肤 × 3 语言 × 6 宽度 × 2 档）；
  `style.css` 增加约 400 行，维护成本上升。接受，因为皮肤是本站的主要表达面。
- **已知边界**：`glass` 的 `--tray-bg` 保持实色（半透明会让卡片透出，守卫禁止）；
  Dela 的 `text=` 子集不能用于任意标题字，官方标题用系统无衬线。
