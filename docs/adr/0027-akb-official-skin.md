# ADR-0027：AKB 官方风皮肤（第三款，默认）

日期：2026-11-01

## 背景

用户要求「多加一个皮肤并设置成默认皮肤，改皮肤和样式特效参考 akb48 官网风格」。
现有两皮肤是 classic（编辑部）与 sticker（生写卡）；参考站 `akb48.co.jp`（2026-11 实测）
的视觉语言是白底、玫瑰粉、细粉线、圆角 CTA、图像优先与固定页头的图标导航。

## 决定

1. **新增第三款皮肤 `akb`（AKB 官方风）**，并设为**新访客默认**。
2. **已有 `akb:skin` 选择不被强制迁移**：保存了 classic / sticker 的访客继续看到原选择；
   只有没有有效存档的访客落到 `akb`。首屏内联脚本、`session.js` 默认值与 `index.html`
   的 seg 选中态必须一致。
3. **只借视觉语言，不复制品牌资产**：不复用官网 Logo/照片/字体文件；以本站的
   `Kami 7` 品牌文字、现有 DOM 与工具流程承载。
4. **令牌 + 组件层**：`style.css` 增加 `[data-skin="akb"]` 令牌块（与 classic/sticker
   键集相同）和一层组件覆盖（页头、CTA、卡片、步骤条、托盘、海报）；
   `poster.js` 继续通过 CSS 变量取色，不复制皮肤逻辑。
5. **无新运行时依赖、无构建步骤**；动效仍受 `prefers-reduced-motion` 与既有令牌约束。

## 后果

- 令牌键集守卫从「两款」扩到「三款」；E2E 首屏矩阵从 2 皮肤扩到 3 皮肤（145→217 检查）。
- `manifest.webmanifest` 的 `background_color` / `theme_color` 跟随新默认（白 / `#d81b60`）。
- classic 与 sticker 的视觉与行为不变；仍可在页头/「更多」里切换。
- 已保存皮肤的访客不会被默认变更打断。
