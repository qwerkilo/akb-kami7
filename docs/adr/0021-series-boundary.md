# ADR-0021 · 系列边界：收「同一组织下的同级团体」，不收整个伞

- 状态：已采纳（2026-10-02）
- 关联：ADR-0008（会话模块）、ADR-0015（档位）
- 依据：加入早安少女家族时两轮 grilling 的 R1-Q1；`docs/agents/data-pipeline.md`

## 背景

加第四个系列「早安少女家族」时，第一个问题就是**边界画在哪**，而这个站已有两个
先例，两个都不一样：

- **48 Group**：AKB48 等七个团体，隶属同一个法人（アップフロント的后身 AKB48 侧），
  共享「总选举」与「神7」这套选拔制度。
- **坂道**：乃木坂46 / 櫻坂46 / 日向坂46，隶属乃木坂株式会社，共享「福神」文化。
- **等爱**：=LOVE / ≠ME / ≒JOY，同一制作人（akeri）旗下，共享合称 #イコノイジョイ。

早安的形状不同：它隶属 **Hello! Project**，那个组织还有六个现役团（angleme /
juicejuice / つばきファクトリー / Beyooooonds / おちゃおちゃ / ロ ElliChronicle）
与两个表演组。**收伞**意味着一次性做八个团；而早安自己的现役成员全部来自这个伞，
所以**收伞会与早安产生成员重叠** —— 同一个「小田さくら」在两个系列里各有一份档案。

一个同类的历史事实也支持「叶」而非「伞」：早安历史上有过组内单元与
さくら組/おとめ組，但都已废止，所以它**现在没有子团体**。

## 决定

**一个系列 = 同一组织下的一组同级团体，不是整个伞组织。**

早安少女系列因此只有**一个团**（モーニング娘。）。站内出现的「早安」一律指这个
团体本身，与 Hello! Project 是**伞与叶**的关系。

## 为什么不是「收整个伞」

1. **成员重叠**是硬伤。伞下的现役团与早安现役 11 人**完全重叠**，档案会有两份。
   本站的名册是「人」的档案（一行 = 一个可排序的人），重叠会直接破坏对决与已选
   的语义。
2. **规模不匹配**。伞有 8 个团、约 150 人，是早安（49 人）的三倍，而它只是
   「早安少女家族」这个请求的顺带扩张 —— 范围一旦顺着伞滑走，就没有终点：
   Hello! Project 还会新增团。
3. **候选池隔离**是站内既有的设计。系列之间互相隔离（ADR-0008），伞与叶之间没有
   隔离语义可依 —— 把伞当一个系列会让「坂道」与「早安」之间少了一层自然的分界。

## 为什么「一个系列只有一个团」也合法

等爱是一系列三团，早安是一系列一团 —— 表面不一致，实则同一条规则的两种结果：
**按「同一组织下的同级团体」切**，而等爱的三个团彼此同级（都直接属于 akeri），
早安在伞下没有同级的其他早安系列团。等爱是**规则的自然结果**，不是另一条规则。

## 后果

- 「系列」这个词从此有了确切含义，改动它要改这条 ADR。
- 新增系列时要先回答一个问题：**这个团体是伞，还是叶？** 答错会造出成员重叠，
  而重叠在本站**不会报错**，只会让同一个人在两个系列里各出现一次 —— 这是要靠
  人（或产物测试）发现的，不是靠异常。
- 伞组织将来若要收，正确做法是**新开一个系列**，而不是把现有系列撑大。
