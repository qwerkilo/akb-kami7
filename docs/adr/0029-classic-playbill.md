# ADR-0029：原版皮肤改为「剧目」版式

- **状态**：accepted（2026-11-01）
- **背景**：原版（classic）原为编辑部版式。用户从三个原型
  （档案目录 / 剧目 / 大报）中选定 **剧目（B）**。
- **决定**：
  1. classic 的令牌改为奶油纸 `#f3ecdc` + 酒红 `#7a1f2b` + 深墨；
     标题居中，挑人页用双细线与 `CAST LIST / ACT I` 小标。
  2. 卡片改为「剧照框」：外框酒红、内框细线；姓名居中并带引导虚线，
     期生/年份用衬线斜体。
  3. **不固定列数**：继续使用 `.gen-body` 的
     `repeat(auto-fill, minmax(var(--card-min), 1fr))`；`seg-cols` 的大/中/小
     仍然决定每行几张，并写入 `akb:cols`。
  4. 窄屏（≤560px）隐藏剧目说明与 CAST LIST、压缩标题，保住首屏见脸；
     实测首屏矩阵 433/433。
- **代价**：classic 的视觉与旧编辑部版式完全不同；首屏矩阵仍覆盖 6 皮肤。
- **验证**：`npm run check` exit 0；`e2e:all` 5/5；主套件 279；
  首屏矩阵 433/433；`seg-cols` 实测 390px 下大/中/小 = 2/3/4 列。
