# ADR-0030：第五种海报样式「接触印相」

- **状态**：接受（2026-11-01）
- **背景**：原有四种海报样式（ADR-0014）都是浅色、贴近皮肤的版式；用户要求增加出图方式，并希望新样式与现有四款有明显区别。
- **决定**：新增 `e` 接触印相（contact sheet）：固定暗房底色 `#101012`、左右胶片齿孔、白边印相纸卡片；7 人用 3/2/2 行、16 人 4×4、40 人 6×7（末行 4）。冠军用白色蜡笔圈，名次与姓名仍消费海报令牌（`card` / `ink` / `pink` / 占位色），皮肤切换不改变暗房底色。
- **理由**：它把「排名」呈现为冲印工作台的接触表，与金字塔/杂志/榜单/拼贴的编辑、封面、榜单、手作语言不同；固定暗房底色让样式本身成为约束，而不是再换一套皮肤色。
- **后果**：`poster.js` 的 `styles` 增至五个；`index.html`、i18n 三语、`test/poster.test.js`、主套件样式 chips 同步。接触印相不提供编辑操作，仅在结果页/分享结果的海报中呈现。
