# ADR-0026 · 获奖级视觉系统：编辑部（classic）+ 生写卡（sticker）

- 状态：已采纳（2026-10-30）
- 关联：ADR-0020（视觉语言）、ADR-0011（皮肤）、ADR-0014（海报样式）、ADR-0019（筛选）
- 依据：用户要求以 Awwwards / Webby / FWA 为品质标准；三轮截图诊断 + 三方向原型对比
  （`prototype/award-2026-10`），用户选 A + C。

## 背景

ADR-0020 已定「杂志感 + 效率区/表现区」，但实现层残留四个结构问题：字阶缺 display 档、
挑人首屏被四层横幅挤占、页头工具与品牌同权重、结果页双层卡片套娃。两皮肤也只是同一版式换色/换阴影，
没有各自的世界观。

## 决定

1. **classic = 编辑部**：纸白/墨黑/荧光粉，系统衬线做大标题，巨大序号成为版式骨架；
   方形图片、细规则线、零圆角，取消双层卡片。
2. **sticker = 生写卡**：拍立得、胶带、印章、剪贴簿；替换现有贴纸皮，不新增第三皮肤。
3. **共享骨架，只换材质**：两皮肤共用同一 DOM 与版式节奏，避免 CSS 面积翻倍。
4. **不引入新字体**：大标题走系统衬线栈，性能与用户自定义标题都不受子集限制。
5. **表现区与效率区仍分离**（沿用 ADR-0020）：挑人/筛选/对决以「一屏一步」为准，
   结果页与海报允许更强的视觉表现。

## 后果

- 需要重写字号/间距/圆角层，并更新 `style-artifact` 的刻度棘轮与截图基线。
- 页头、步骤条、托盘、结果页 DOM 会调整；`app.js` 接线必须用 E2E 验收。
- 旧 sticker 视觉被替换，属于有意的破坏性变更；回滚方式是整体 revert 本 ADR 批次。

## 备选（未采纳）

- **舞台（深色聚光）**：气氛强，但早期低分辨率照片在深色下更显脏，且与「快速筛选」冲突。
- **只改结果页**：改动小，但页头/挑人仍是旧语言，整体不成立。
