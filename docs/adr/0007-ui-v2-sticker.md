# UI v2 采用「D · 贴纸网格」方向（原型留档于 prototype/ui-v2 分支）

UI 重做评估了四个变体（A 杂志编排 / B 暗色舞台 / C 明亮极简 / D 贴纸网格），经单页原型（`?variant=` 切换 + 浮动切换条）实际比较后选定「D · 贴纸网格」：Bento 大小块网格、粗描边贴纸语言、糖果色、微旋转海报格。选定方向折叠进正式实现（**按原型重写，不搬运原型代码**）；未选变体与原型页保留在 `prototype/ui-v2` 分支（提交 `8b74913`）作为原始资料，实现工单指向该分支。

## Considered Options

- A 杂志编排：编辑感强，但信息密度与操作效率偏低。
- B 暗色舞台：沉浸，但暗色在强光环境与分享海报上不占优。
- C 明亮极简：克制干净，但与偶像应援语境的气质距离最远。
- D 贴纸网格：活泼、弹性网格适合头像卡，分享图气质贴合。

## Consequences

- 后续 UI 迭代遵循贴纸语言（粗描边、硬阴影、圆角、糖果色）；若改方向需重开原型。
- 原型代码是原型约束下的产物（无测试、无错误处理），正式实现必须重写。
