# 32 人档位采用精确全序，用进度体验补偿题量

32 人档位的最坏对题数为 129（7 人为 14、16 人为 49），接近全序排序的理论下界（log₂(32!) ≈ 118）。决定不做分组制或淘汰制近似：海报要排满 32 席就必须全序，且归并排序已有可回放的实现；题量靠体验手段补偿——进度百分比、剩余（最坏口径）题数、预计时长、退出续玩。

## Considered Options

- 分组制（4 组 ×8 先组内排序，再组间小排序）：题数明显下降，但结果不是全序，与「排出 32 人名次」的目标不符。
- 淘汰制：只产出前 N，与海报排满 32 席冲突。

## Consequences

- 32 人模式是长流程（平均 100+ 题），持久化与续玩是它的组成部分，而非可选优化。
