# ADR-0014：海报四样式（默认金字塔，样式与皮肤正交）

日期：2026-09-28
状态：已采纳

## 背景

海报原先只有一种版式（金字塔）。用户要求「保留现有版式为默认，其余可选、可切换，下载即当前样式」，并已通过原型选定四种方向（`prototype/ui-v6-poster`，提交 `4982832`）。

## 决策

- **四种样式**：a 金字塔（默认，即原版式）／b 杂志封面／c 榜单领奖台／d 贴纸拼贴；`poster.js` 导出 `styles = ["a","b","c","d"]`，`draw()` 按 `opts.style` 分派，缺省等价于 a。
- **正交于皮肤**：样式决定版式，皮肤决定视觉令牌；三新样式全部消费 `colors`/`fonts`/`cardStroke` 令牌（奖牌金银铜为样式语义常量）。任一样式在两款皮肤下都成立。
- **选择为全局偏好**：持久化键 `akb:poster-style`（与 `akb:skin`、`akb:state:v2:*` 并列），非法值回退 a。
- **导出即当前样式**：保存/长按保存都取同一 canvas；分享文案与文件名保持 `names().fileBase` 不变。
- **几何与高度解耦**：三新样式的横向几何按可用宽度预算缩放（如领奖台的 `kx`），7/16/40 与 1440/1920 两种画布都成立；越界不变量由单测（假 ctx 仿射矩阵 + 四角检查）守卫。

## 影响

- 结果页新增样式 chips（三语文案），默认无需迁移（默认即旧行为）。
- 测试面：`test/poster.test.js` 的不变量用例覆盖 4 样式 × 3 档；C 的领奖台另有「互不重叠且居中」用例；令牌响应有专门用例。
- 后续若要替换/新增样式，只需在 `poster.js` 增一个 `draw*` 并扩 `styles`，UI 与持久化无需改动。
