# 等爱系列纳入三团；数据以官网 + 日文 Wikipedia 合成，照片三级回退

站点新增第三个系列「等爱」（=LOVE、≠ME、≒JOY，指原莉乃制作；合计 37 人 = 现役 33 + 毕业 4），扩展 ADR-0004 的系列隔离到三个系列。官方站（equal-love.jp / not-equal-me.jp / nearly-equal-joy.jp）是现役照片与档案（血型、星座、身长、生年月日、出身地、趣味、特技）的来源，但只有罗马字读法、没有毕业成员；日文 Wikipedia 提供平假名读法、生年月日、出身地、元成员表与卒業日。决定两源合成；照片按 **官网 → Web Archive → Wikipedia/Commons → 占位图** 回退（实测毕业成员官网图多已下架：佐竹のん乃、齊藤なぎさ、福山萌叶为 500，菅波美玲仍在；福山在 Web Archive 有快照，齊藤/佐竹在 Wikipedia 有自由许可照片）。

## Considered Options

- 只用官网：无假名读法、无毕业成员——与「含毕业成员」的范围决定冲突
- 只用 Wikipedia：现役照片只有官网有；档案字段（趣味/特技）也更少
- 毕业成员不补图、直接占位：用户选择先试 Web Archive 与 Wikipedia 图，兜底才是占位图

## Consequences

- 数据管线新增一个外部源（三个官网 + ja.wikipedia）与一条照片回退链；个别毕业成员仍可能是占位图（可接受）。
- 等爱系列候选池 37 人，7/16/32 三档均可用；系列隔离、按系列持久化等既有规则自然扩展。
