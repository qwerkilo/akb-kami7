# 48 Group 与坂道系列互不混选，玩法名随系列

站点新增坂道系列（乃木坂46、櫻坂46、日向坂46）后，用户可在两个系列间切换。决定：两个系列各自拥有独立的候选池、已选、对决进度与海报；不提供跨系列混选，也不做「48G+坂道」联合排序。玩法名随系列：48G 侧为「神7」，坂道侧为「7福神」（坂道选拔文化中的「福神」）——「神7」是 48G 专属概念，不用于坂道。16 人档两个系列共用「选拔组」，32 人档两个系列共用「圈内」（取自总选举概念，两系列统一）。

## Considered Options

- 允许跨系列混选（一张海报混排 48G 与坂道成员）：会滑向另一种产品（排序失去各自的共同体语境），且神7/7福神 的品牌名会打架。
- 全站改中性名（7人版/16人版/32人版）：丢失各自圈层的称谓，两个系列的文化感都被稀释。

## Consequences

- 切换系列时保留各自状态；搜索、筛选、结果与海报均限定当前系列。
- 海报话题标签分开（#48Group / #Sakamichi）。
