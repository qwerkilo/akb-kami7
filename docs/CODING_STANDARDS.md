# 编码规范（阿里巴巴 Java 开发手册的可迁移版）

本仓库是 **JS + Python 的静态站与数据管线**，没有服务端、构建步骤与运行时框架。
《阿里巴巴 Java 开发手册》里针对 Java 语言/框架的条目（JVM、线程池、集合实现、MyBatis、日志门面等）
**不适用**；这里只保留与语言无关、能在本仓库落地并检查的部分。原文是权威，本文是适配口径。

## 1. 命名

- JS 函数/变量 `camelCase`，构造函数/类 `PascalCase`，常量 `UPPER_SNAKE_CASE`；Python 模块/函数/变量 `snake_case`，类 `PascalCase`，常量 `UPPER_SNAKE_CASE`。
- 名字必须说明**做什么**，禁止 `data1`、`tmp`、`foo`、拼音缩写；布尔值用 `is/has/can/should` 前缀。
- 文件名与被导出的概念一致；生成物（`members.js`、`bios.js`、`simplified.js`）不手改。

## 2. 常量与魔法值

- 业务常量、阈值、颜色、时长、键名一律命名；同一值只允许一个定义点。
- 皮肤/样式/令牌的单一出处见 `core.js` 的 `SKINS`、`poster.js` 的 `styles`、`style.css` 的令牌块；持久化键只用 `core.PREF_KEYS`。
- 注释和文档**不写会漂移的当前值**（行数、像素、题数）；让测试或代码常量持有它。

## 3. 函数与方法

- **单个函数 ≤ 80 行**，**参数 ≤ 4 个**；超过 4 个时传一个具名对象（如 `{ x, y, w, h }`），不要堆位置参数。
- 嵌套深度 ≤ 3（`if/for/try` 合计）；超过时提前返回或抽函数。
- 一个函数只做一件事；绘制函数按「背景 / 标题 / 主体 / 页脚」拆分，不把五种版式写进一个函数。
- 圈复杂度 > 10 的函数必须登记在 `docs/reviews/complexity-baseline.txt`，新增/变高会被闸门拦住。

## 4. 模块与解耦

- 按**能力/相位**分包，不按文件类型分包：`poster-core`（原语）与 `poster-layouts`（版式）、`app-pick`/`app-screen`/`app-duel`/`app-result` 各自拥有一个相位。
- 模块只通过公开接口通信；跨模块不读对方的内部变量、不复制对方的常量。
- 浏览器与 Node 共用同一份实现：UMD 包装（`root.AKB_*` / `module.exports`），不要在浏览器分支里重写一份。
- 新增客户端脚本必须同时更新 `index.html` 的加载顺序与 `sw-cache-rules.js` 的 `SHELL_FILES`；PWA 离线承诺不能因分包退化。

## 5. 异常与错误

- 禁止空 `catch`；确实可恢复时写清恢复语义（例如「隐私模式下存储不可用，按未持久化继续」）。
- 数据管线的失败必须分类（查询失败 / 源里没有 / 预算截断），不得把失败静默降级成「没有」。
- 写产物前做门禁（规模、名字漂移），失败时中止而不是写入半成品。

## 6. 注释与文档

- 注释解释**为什么**，不复述代码；公开函数写 JSDoc/Python docstring，内部函数按需。
- 过期注释视为缺陷：本仓库出现过「6×6」与「白色蜡笔圈」两处漂移；改实现时同步改注释或删掉数字。
- ADR、`CONTEXT.md`、检查点只记录决策与理由；当前状态用测试/命令输出表达。

## 7. 测试

- 测试只落在既有的七处缝（见 `AGENTS.md`）；新增缝先与维护者确认。
- 行为改动先写能红的测试（TDD）；重构不改变行为时，用既有测试 + 字节比对 + E2E 兜底。
- 机械性规范用闸门守，判断性规范在 `docs/reviews/review-rules.md` 由审查者核。

## 8. 安全与数据

- 所有数据派生字符串进 `innerHTML` 前必须 `esc`；属性值用双引号。
- 不读不写非 `PREF_KEYS` 定义的持久化键；不把用户标题直接拼进选择器。
- 不提交密钥、签名、令牌；签名文件只留在本机 NP 目录。

## 9. 机械检查（`npm run check`）

| 检查                 | 守什么                              |
| -------------------- | ----------------------------------- |
| `prettier --check`   | 格式                                |
| `lint:undef`         | 未定义标识符                        |
| `npm test`           | 单测 + 产物守卫                     |
| `npm run complexity` | CCN 趋势（新增/变高）               |
| `npm run standards`  | **方法 ≤80 行、参数 ≤4** 的趋势棘轮 |

存量违规登记在 `docs/reviews/standards-baseline.json`；重构降低后运行
`node scripts/standards.mjs --update` 收紧基线。**只许收紧，不许为过检查抬高基线。**
