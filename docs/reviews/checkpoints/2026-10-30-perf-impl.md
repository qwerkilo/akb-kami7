- **日期**：2026-10-30
- **本次基点**：`3e5c250`
- **审查范围**：wayfinder 06/07 已决项的首批实现（`sw.js`、`sw-cache-rules.js`、`app.js`、`core.js`、E2E 与单测）。
- **结论**：
  - **SW 重复 index**：`SHELL_FILES` 同时列了 `"./"` 与 `"index.html"`（同一文档两份 25KB）；
    删 `"./"`，并让根导航统一存 `index.html`（`navKey`）。壳缓存 **16 → 15 条**，
    PWA 套件新增「没有重复 index 副本」断言。
  - **搜索上限**：`SEARCH_RENDER_CAP` **80 → 40**；主套件断言与「还有更多」提示同步。
  - **预览编码**：`toDataURL` → `toBlob` + object URL。同条件单测（1080×1440）冷态
    **156.9 → 63.3ms**，热态 45–59 vs 42–50ms；base64 字符串（1.5–1.7MB）不再保留。
    **未达标**：40 人整条海报 longtask 仍为 208–419ms（`draw` 本身 69–241ms 波动），
    没到决议里的 ≤100ms；收益是编码峰值下降，不是整条任务缩短。
  - **字体权重平局**：`closestWeight` 按 CSS Fonts §5.2（>500 选更大、否则更小），
    600 不再同时预热 500/700、800 不再同时预热 700/900；缝② 测试 + 变异被杀。
- **验证**：`npm run check` exit 0；`e2e:all` **5/5**；变异 **4/4 被杀**
  （权重平局 / SW canonical / 搜索 40 / 预览不写 src）。
